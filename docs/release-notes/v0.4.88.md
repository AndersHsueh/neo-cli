## 为什么发

v0.4.87 拆分大文件后留下一批机械残留：命令组等拆分产物整段复制了原 import 区，`src` 下 `tsc --noUnusedLocals` 有 591 条未用告警；共享可变字段改写时有 21 处语句或注释挤在同一行；`src/config.ts` 用 `export *` 再导出 `config/types.ts`，把内部解析辅助也变成了公共 API。本版一次清掉，并加守卫防止回退。**无行为变化。**

## 已知未做（后续）

8. `scripts/verify.sh` 的 tsc 证据文件成功时没有结果行与退出码，建议在 `run_stage` 末尾追加 `exit: <code>`。
9. `tests/` 22 条、`scripts/` 3 条未用 import / 局部；清完后再考虑把 `noUnusedLocals` 写进 `tsconfig.json`。
