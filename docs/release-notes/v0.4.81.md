## 变更

### 修复

- **`!cmd` 在 ask 模式下死锁（#34）**：`runShellWithTui` 先 suspend 输入框、再在 `runShell` 里弹确认框 —
  挂起后确认框根本画不出来，shell 从未执行。拆成 `authorizeShell`（只授权，在挂起前弹框）/`executeShell`
  （只执行）；PTY S23 升级为完整链路断言（进入 `!` 模式 → 确认 → 执行 → 之后继续输入）。
- **`max_tokens` 边界发现（#8）**：`settings.max_output_tokens` 的写回/补全（报错文案解析出的精确上限、
  可选的受控主动探测，默认关）。

### 增强

- **路径作用域项目规则（#17）**：`.neo/rules/**` + `.claude/rules/**`，`paths` glob 条件加载；每会话规则并入
  项目记忆，scoped 规则按「本轮触达路径」以临时 system 消息注入；`/context` 可见命中原因。
- **输入框 `!` shell 模式（#30）**：空缓冲键入 `!` 进模式（前缀/配色切换），回车执行、空回车不执行、
  删空/Esc 退出；旧的一行式 `!cmd` 保留。
- **`/loop` 定时 / 自节奏循环（#25）**：`/loop 2m <提示>`、`/loop self <提示>`、`/loop stop`；忙碌时丢拍不排队。
- **`/` 渐进式命令菜单（#31）**：行首 `/` 自动开菜单（左名/右说明）、边打边过滤、↑↓ 导航、Tab 接受、
  Enter 执行；TUI 移除旧的「N 个命令候选」单行 hint。
- **MCP 远程 HTTP 传输（#29）**：`mcpServers` 支持 `{ type: "http", url, headers }`（streamable HTTP，
  JSON/SSE 双响应、session 回带）；工具/审批/plan 口径与 stdio 完全一致；SSE 旧传输与 OAuth 列入非目标。
- **后台子代理（#16）**：`task(background: true)` 立刻返回、完成结果自动注入；`/tasks` 列表/取消；
  并发上限 3；ESC 不误杀后台（PRD 写明口径）。
- **后台长驻 shell（#28）**：`shell(background: true)` 立刻返回 `sh-N`；前台超时**转后台而不是杀进程**；
  `shell_output` 按 id 读输出；`/ps` 列表/停止；会话退出清理。
- **仓库地图（#15）**：系统提示词注入符号级地图（TS/JS/Python/Go/Rust），预算默认 800 tokens、20s 缓存；
  `repo_map` 可配/可关，`/context` 一行状态。
- **按轮次回滚 `/rewind`（#27）**：按用户轮次聚合快照，可只退代码 / 只退对话 / 两者一起；轮次表随会话
  保存（`--resume` 后仍可用）；`/undo` 原样保留。
- **目标驱动自动续跑 `/drive`（#24）**：完成条件只认可验证信号（检查命令 exit 0，模型自述不算）；
  未通过自动再排一轮，上限/连续空转/`stop` 停；与 `/goal` 锚点语义分写。
- **LSP 代码智能（#23）**：配置驱动的语言服务器接入（不捆绑）；`write_file`/`edit_file` 后回灌诊断摘要；
  只读工具 `lsp` 支持 definition/references/hover。
