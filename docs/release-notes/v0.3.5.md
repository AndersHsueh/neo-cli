# v0.3.5

本版不引入新功能面，只修 `docs/neo-vs-claude-code-20261026.md` 评估中列出的 6 个 P0：
目标是把「能完成」的稳定性补上，让长会话、坏网络、大仓库、自动化场景不再踩坑。
每项独立 commit，按顺序可单独 revert。

## 修复

### 1. `edit_file` 不再静默写坏含 `$` 的代码（`c0d8443`）

`String.replace(old, new)` 会把 `new_string` 里的 `$&`、`$1`、`$$`、`` $` ``、`$'`
当成替换模式展开（实测 `s.replace(/a/g, "$&")` 被写成 `s.replace(/a/g, "normal")`）。
单次替换改为 `split/join`，按字面写入。

### 2. LLM 请求重试 + 超时（`0c90a2e`）

- 只重试「尚未向用户输出任何增量」的失败：网络错误 / 408/409/425/429 / 5xx；
  已输出后中断一律不重试（避免重复正文与重复工具调用），错误信息说明已输出字符数。
- 指数退避 + 抖动（封顶 8s），429 优先遵守 `Retry-After`（封顶 30s）；退避期间可被 ESC 立即打断。
- 连接/首字节 30s、流式空闲 120s（每 chunk 重置）；用户取消不重试。
- **SSE 收尾检测**：既无 `[DONE]` 也无 `finish_reason` 却 EOF，判为连接被掐断并显式失败，
  不再把半截内容当完整答案。
- 新增配置段（可选，缺省即推荐值）：

```json
"retry": {
  "max_attempts": 3,
  "base_delay_ms": 500,
  "connect_timeout_ms": 30000,
  "stream_idle_timeout_ms": 120000
}
```

### 3. 压缩保留近期原文（`46faaa0`）

- 旧实现：摘要器每条消息只见 160 字符；压缩后历史只剩一条摘要。
- 现在：摘要较早历史 + **保留最近 ≥6 条原文**；切点落在 user 消息前，不拆
  `assistant(tool_calls)` ↔ `tool` 配对；摘要输入单条上限 160 → 2000 字符（总输入 60k 封顶）；
  压缩调用自身 usage 计入累计。
- 效果：超过 75% 窗口后，最近的 `文件:行号` / 命令 / 错误栈仍以原文存在。

### 4. grep / glob 尊重 `.gitignore`、包含隐藏文件（`cf324b9`）

- git 工作区：用 `git ls-files -z --cached --others --exclude-standard` 枚举
  （tracked + untracked、排除 ignored、含隐藏文件、软链目标展开）。
- 非 git 目录：JS 遍历 + 最小 `.gitignore` 匹配器（`#`、`!`、尾 `/`、前导 `/`、`**`、子目录规则）。
- 匹配仍用 JS 正则，`\d`、lookahead 等语义不变（不切 `git grep` 的 POSIX ERE）。
- 输出标注「已按 .gitignore 排除」；枚举超 20k 文件时提示截断。

### 5. 写文件检查点 + `/undo` `/checkpoints`（`6c10784`）

- `write_file` / `edit_file` 审批通过后、写盘前把原文件快照到
  `<cwd>/.neo/backups/<sessionId>/`，manifest 为 JSONL（崩溃只丢最后半行）。
- 每会话保留最近 100 条；单文件 >2MB 只记 manifest 不复制；只快照工作目录内路径。
- 新命令：`/undo [n]`（逆序还原，默认 1）、`/checkpoints [n]`（列出最近记录）。
- **边界**：不覆盖 shell / 外部进程的修改（文档与 HELP 均写明）。

### 6. `-p` 结构化输出 + 退出码（`795fe31`）

- 新增 `--output-format text|json`（仅 `-p`）。json 模式 stdout **只写一行 JSON**，
  所有 UI/流式/工具输出改走 stderr；text 模式输出保持不变。
- JSON（v1）：`ok / exit_code / answer / error / finish_reason / aborted / duration_ms /
  usage{prompt,completion,reasoning} / tool_calls / iterations / model / provider /
  session_id / tier_switch`。
- 退出码：`0` 成功、`1` LLM/agent 失败、`2` 用法错误、`130` 用户中断。
- 推荐自动化组合：`neo -p "<任务>" --output-format json -y`。

## 兼容性 / 升级注意

- 行为变化（均为修正方向）：
  - grep/glob 不再返回被 `.gitignore` 忽略的文件，也不再漏掉 `.github/` 等隐藏目录；
  - 压缩后历史会保留最近原文，`/compact` 后消息数不再是 2；
  - 含 `$&` 的 `edit_file` 现在按字面写入（旧版会写坏）。
- 新配置段 `retry` 可省略；省略时使用默认值。
- `.gitignore` 新增 `.neo/backups/`（本地恢复状态，不入库）。
- 版本双源 bump `0.3.5`（`package.json` + `src/index.ts`），
  `scripts/verify.sh` 的 `EVIDENCE_PREFIX` 同步为 `v0.3.5`；tag `v0.3.5`。
