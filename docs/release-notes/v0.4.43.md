# v0.4.43 — AGENTS.md 区块边界只认独占一行的标记

## 问题

`composeAgentsContent` 用子串匹配找 START/END。用户正文里引用标记（如 `- 别手改 <!-- ...start ... --> 之间的内容`）会被当成边界或清理目标，整行或前面手写内容被静默删掉。

## 改动

- `src/memory/agMd.ts`：`START_LINE_RE` 锚定整行；`isMarkerLine` / `findMarkerLine` 只认独占一行的标记
- `tests/memory-agmd.test.ts`：行内含标记的 3 条回归

## 验证

- `bun test`：1150 pass / 0 fail / 71 files
- `bunx tsc --noEmit`：exit 0
