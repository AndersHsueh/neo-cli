## 变化

- 启动 banner 标题：`N E O` → **`M.A.T.R.I.X`**（保留 `wake up, neo... the matrix has you.` 副标题）。
- banner 底部第二条横线删除，改为**一个空行**。原因：输入框顶线就在 banner 下方，两条横线贴得太近
  在「首次启动、还没有任何会话输出」时很突兀；现在只保留标题下第一条横线。
- 空行用「一个空格行」实现（不是纯空串）：composer 的 `wrapAnsi` 会忽略尾部空串，空格行才能稳定落成空行。

PTY 实际启动效果：

```
  M.A.T.R.I.X    wake up, neo... the matrix has you.
────────────────────────────────────────────────────────────
  provider ipsa [default]
  model  glm-5.3-flash
  endpoint ipsapro.isoftstone.com
  tools  read_file ... send_message list_peers

❯  输入消息 · @ 文件 · / 命令 · Ctrl+J 换行
────────────────────────────────────────────────────────────
fake-model · default · ask · ctx ...
```
