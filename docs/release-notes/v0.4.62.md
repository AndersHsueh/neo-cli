# v0.4.62 — stdio MCP 工具接入（issue #2）

## 背景

MCP（Model Context Protocol）生态里现成工具很多，neo 此前只能用内置工具。本版（issue #2）支持连接配置的 stdio MCP 服务器，把外部工具注册进 neo。

## 改动

- 新增 `src/mcp/`：`jsonrpc.ts`（265 行，JSON-RPC 通道）、`client.ts`（376 行，stdio 客户端）、`tool.ts`（332 行，工具桥接）、`index.ts`
- `src/config.ts`：settings.json 新增 `mcpServers` 配置段
- 工具命名：注册为 `mcp__<server>__<tool>`，**顺序无关且 API 合法**（防重复注册冲突——工具注册表重复注册会抛错）
- 审批路径：MCP 工具调用走共享审批路径——auto-edit 模式下仍需确认，plan 与 `/review` 下拒绝
- 可读的连接失败报错；所有退出路径上清理子进程
- `/mcp` 命令查看连接状态；README 文档
- 测试用 fixture MCP server（`tests/fixtures/mcp-server.ts`）做端到端验证
