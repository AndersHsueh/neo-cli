## 为什么发这一版

v0.4.84 之后积了 12 个提交没发版，其中 4 项是真功能/真修复。这一版把它们收口：

- **#37 stream-json**：`-p` 有了机器可读的流式输出，CI / 编排能实时消费，不必等进程结束再解析 stdout。
- **#59 模型备用链**：主模型故障时按序切备用，不再一挂就整个会话停摆。
- **#52 默认关闭 LSP / 仓库地图**：这两项默认开启会抬高启动成本与提示词预算，改为显式开启。
- **#39 Windows 记忆续页**：跨平台路径拼接修复（`split("/")` → `basename`）。

## 变更

### #37 `-p --output-format stream-json`：流式 JSON 事件

```bash
neo -p "把测试修到全绿" --output-format stream-json
```

- **只能与 `-p` 同用**：stdout 纯 JSONL（每行一个事件信封），人看的文本全部让位。
- **v1 事件表**（`src/streamJson.ts`）：`init` / `turn_started` / `assistant_message` /
  `tool_started` / `tool_finished` / `model_fallback` / `drive_finished` / `error` / `result`。
- **`result` 是唯一出口**：每次运行必以一条 `result` 收尾，带 `status` / `exit_code` /
  `provider` / `model` / `usage` / `drive` / `error`；`exit_code` 与进程退出码同源（0/1/2/3/130）。
- **截断与脱敏**：长文本走 `ClippedText`（`text` + `truncated` + `original_chars`，按 Unicode
  code point 计）；API key 等敏感串在写入前脱敏。
- **`model_fallback` 事件**：备用链切换时单独上报（`from` / `to` / `reason`），消费方可区分
  「正常完成」与「降级完成」。

### #59 有序模型备用链

```bash
neo --fallback ipsa:deepseek-flash --fallback ipsa:glm-5.3-flash -p "..."
```

- 配置项 `settings.model_fallback`（顶层数组），CLI `--fallback <provider>:<model>` 可重复，
  **出现顺序即优先级**；任一项出现即完整替换配置文件里的链；最多 8 项。
- `--no-fallback` 本次禁用备用链，与 `--fallback` 互斥。
- 失败归因走 `attributeFailure()`：区分可切换故障（网络 / 5xx / 限流）与不可切换故障
  （鉴权 / 参数错误），后者不浪费备用额度。
- 切换过程对用户可见（TUI 提示 + stream-json 的 `model_fallback` 事件）。

### #52 LSP / 仓库地图默认关闭

- `DEFAULT_LSP.enabled` 与 `DEFAULT_REPO_MAP.enabled` 改为 `false`；显式写 `true` 能力完整保留。
- `lsp` 工具的可见性（`toolSpecs` / `toolNames` / `mainToolNames` / `dispatch`）按
  `cfg.lsp.enabled` 过滤；系统提示词里的 lsp 说明改为条件渲染。
- `PromptManager` 缓存指纹纳入这两个开关，避免开关切换后命中旧提示词缓存。
- **`driveExitCode` 区分来源**：verified done → 0、model done → 3、其它/无来源 → 1；
  单次模式优先级固定为 `abort > hadError > drive`。

### #39 Windows 记忆续页路径拼接

- `src/memory/merge.ts`：续页文件名改用 `basename` + 计数器，不再 `split("/")` 取尾段
  （Windows 反斜杠路径下会取错）。
- 顺带给 `dropped` 补上上下文，便于排查丢弃原因。
