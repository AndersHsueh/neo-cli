# v0.1.12

> 2026-10-20 · 补丁版本：**记忆旧件清理** —— 删除 deprecated 实现、未使用模板与陈旧 wiki 页
> 规格：`docs/001-memory-system-design[done].md` §7（变更记录见 §7.0.1；旧件处置最终状态见 §7.11）

## 背景

v0.1.11 把记忆链路接通后，v0.1.0 时代的「空转实现」全部失去生产调用点，但仍留在仓库里：
它们有测试、有导出、看起来像能力，实际没有消费者。仓库作者要求「无用且过期的内容一定要尽早清理」，
本版本做一次彻底的代码/配置/文档清仓，并保留 git 历史作为唯一回逆路径。

### 配置（MemoryConfig 删除 10 个从未被消费的字段）

`cwdRelativeMode` / `worktreeIsolation` / `maxProfileChars` / `profileTokensLimit` / `ingest` /
`autoWriteIndex` / `noProfileInOneShot` / `platform` / `piiFilter` / `ingestJournal`。

### 资源与陈旧内容

- `src/wiki/templates/`：删除 4 个无引用模板（`wiki-INDEX.md` / `wiki-log.md` / `raw-README.md` / `outputs-README.md`）；保留被代码使用的 `agents-wiki-section.md`、`ingest-prompt.md`。
- `.neo/wiki/wiki/工作流-ingest-query-lint.md`：karpathy 技能时代（v0.1.4 前）的孤儿页，从未进 INDEX、仅靠 lint 豁免存活；删除并从 lint 豁免表移除。
- `.neo/wiki/AGENTS.md`：把「三类操作工作流」从已退役的 `/karpathy-wiki-*` 技能改写为现行工具入口（`/ingest`、`wiki_search`/`wiki_write`、`/wiki-lint`），并注明自动记忆归纳走同一写回路径。

## 保留（有生产消费者）

- `locks.ts`：仅保留通用锁 `acquireLock` / `tryAcquireLock`（含 stale 自愈）/ `releaseLock` / `withLock`；删除旧 cwd 锁 API。
- `pii.ts`：journal 与提炼器仍在用。
- `init.ts` + `agMd.ts`：`/init` 骨架与 AGENTS.md 区块所有权仍在使用。
- `bridge.ts` 中的 `migrate()` 与旧 `profile.md` 读取：仅作为**数据迁移兼容**保留，不是旧实现。

## 验证

- 新增 `tests/memory-core.test.ts`（13 例）：配置默认/环境变量、PII、`/init` 骨架幂等、`MemoryError`、以及「清理守卫」（断言 8 个 deprecated 文件、4 个模板、陈旧 wiki 页不得复活）。

- 删掉的文件全部可在 git 历史中找回（本版本之前的 tag `v0.1.11`）。

- `recordIndex`/`profile`/`ingest` 的测试基线数字不再存在；后续以 445 为基线。
