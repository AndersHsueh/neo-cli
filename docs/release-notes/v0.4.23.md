# v0.4.23 —— htmlToText 单次实体解码

## 为什么

`htmlToText`（web_fetch）旧版链式 `.replace()` 解命名实体后再跑数字实体，
于是 `&amp;lt;b&amp;gt;` 被二次解码成真标签再被剥掉；`&amp;#65;` 解成 `A`。
与 v0.4.22 的 web_search 单次解码不对齐。

## 改了什么

- `entities.ts`：新增 `decodeHtmlEntities`（命名+数字同一遍 `replace`）
- `htmlToText`：先剥标签，再一次调用 `decodeHtmlEntities`
- 审阅修正：命名组勿塞 `#39`，否则 `&#39;` 抢匹配且不解成 `'`

## 测试

`&#39;`/`&#x27;`、双重转义停在字面量、单层不回退。
全量 1108 pass / 0 fail；`tsc --noEmit` 干净。
