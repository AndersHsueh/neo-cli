### 1.2 Skills 工作详解(`c8d7022` 主体 + `d2487d0` + `d2ac497`)

#### 1.2.1 机制(三层披露)

- **第 1 层(索引常驻 system prompt)**:neo 启动时扫 `<cwd>/skills/`(支持软链)与 `~/.neo/skills/`,把 `(name, description 截断到 40 token)` 注入 system prompt。
- **第 2 层(SKILL.md 正文按需)**:模型在觉得相关时调 `use_skill(name)`,neo 走 `resolveSkill(name)` 返回正文 + 附件清单 + 来源说明。
- **第 3 层(附件再按需)**:正文里若引用附件名,模型再调通用 read 工具读(`src/skills.ts:6:12`).

#### 1.2.2 查找与软链落地

```
1. <cwd>/skills/<name>/ 存在(真目录或软链)→ 直接用,不动全局库
2. 否则全局库 ~/.neo/skills/<name>/ 有 → 建软链 <cwd>/skills/<name>(绝对路径、幂等)
3. 都没有 → use_skill 抛 ToolError,dispatch 转 ok:false,记入连续失败数让模型能感知
```

(`src/skills.ts:338 339`)

#### 1.2.3 关键 bug 修复:symlink 遍历

`readdirSync(withFileTypes)` 对 symlink 返回 `isDirectory()=false`,直接 glob/grep 对软链完全失效。新增 `isRealDir(full, e)`(`src/skills.ts:178`):symlink 时用 `statSync` 跟随判断目标类型。

注意不能用 `e.isDirectory() || e.isSymbolicLink()` —— 那会把"软链到文件"当成目录走进 walk,`readdirSync` 抛错被 catch 吞掉,该文件永远匹配不到。

#### 1.2.4 安全三件套

- 写工具用 `realpathSync` + 逐级上溯拦截穿透 symlink 写入全局技能库
- 技能名白名单 `isValidSkillName()`(`src/skills.ts:53`),拒绝路径穿越
- `/skills` 是只读诊断入口,不建软链(诊断命令不应改动用户项目目录)

#### 1.2.5 隔离守卫(d2ac497)

原先 K1 / K4.2 硬绑了 `feature-skills` worktree 名字与".git 必须是 worktree 指针文件"——一删 worktree,9 个 K 组用例全 fail;工作流从"worktree 模式"退化为"直接在 main 跑"时无法继续。

修复后:
- K1: 列表含 ROOT 的 basename 即合法(脱离硬绑 worktree 名)
- K4.2: 主仓(`.git` 目录含 `HEAD/config`)与 worktree(`.git` 是 `gitdir` 指针文件)都算合法
- `assertWorktreeHealthy`: 从硬绑名字改为"列表非空",与 ROOT 解耦

## 三、用户必做的本地配置变更

### 3.1 背景

`neo/settings.json` 在 `.gitignore` 里(`neo/.gitignore:3`),**不进任何 commit**。所以本仓库的 `v0.1.0` tag 不会"自动修好"你本地的坏配置——你必须手动改一行。

### 3.2 必改

**L44 改前**:
```json
"fast": { "provider": "ipsa", "model": "l-deepseek-v4-flash" },
```

**L44 改后(三种等价)**:
```json
"fast": { "provider": "ipsa" },
"fast": { "provider": "ipsa", "model": "" },
"fast": { "provider": "ipsa", "model": "deepseek-flash" },
```

`routeModel()`(`src/config.ts:416`)在 `route.model` 缺失 / 空字符串时,回落 `provider.fast_model_name`(本例 `ipsa.fast_model_name = "deepseek-flash"`)。

### 3.3 凭据(Huang n=3, 2026-10-16 实测)

| 模型 | 最短 | 最长 | std | 3/3 命中 | 评价 |
|---|---|---|---|---|---|
| `l-deepseek-v4-flash`(改前)| 0.52s | 180.51s | ≈ 87s | 2/3(1 次 502)| 判死 |
| `deepseek-flash`(改后)| 0.98s | 1.40s | ≈ 0.2s | 3/3 | 稳 |

判死依据: 3 个 backend 池乱跳,差 ≈ 350×;改后稳定走 `Deepseek/deepseek-v4-flash-202605` 快照。

### 3.4 改完验证

```bash
neo --provider ipsa
# 进入 session,执行:
/tier fast
# 然后随便提个简单问题,观察:首 token 应在 2 秒内,无 502
```

或单次命令行验证(无需入 session):

```bash
neo -p ipsa -t fast <<< $'1+1='
```
