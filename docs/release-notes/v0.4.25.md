# v0.4.25 —— rewriteSearchUrl 幂等、保参、字面 `+`

## 为什么

1. `cn.bing.com` 是改写目标，须显式幂等，避免将来把 bing 加进搜索主机表后改写自身并谎报不可达。
2. 旧版只保留 `q`，丢掉 `hl`/`num` 等参数。
3. `URLSearchParams` 把 `+` 当空格，`?q=c++` 变成「c  」。对本项目主路径（模型用 `encodeURIComponent` 拼 URL，空格是 `%20`、加号是 `%2B`）保留字面 `+` 更稳。

## 改了什么

`rawQueryParam` 只解 `%XX`；改写时保留其余查询参数；`cn.bing.com` / `www.cn.bing.com` 原样返回。

## 测试

全量 1113 pass / 0 fail；`tsc --noEmit` 干净。
