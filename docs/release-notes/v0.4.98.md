## 变更

1. `6f01837d521964f33ae864d8b44f751e57579fba`（feat: 会话默认名改为顺序编号 Neo#N，#82）：
   - 默认会话名为单调递增的 Neo#N，关闭后不复用。计数器落在既有 mailbox 存储下（mailbox 根目录的 `default-name-seq.json`，可由 `NEO_MAILBOX_DIR` 覆盖）。并发启动不得拿到同一编号。可读但缺失/损坏的计数器按已知最大 Neo#N+1 恢复，不报错。
   - 优先级：`--name` > `--resume`/`--continue` 旧名 > 默认 Neo#N。resume 保留历史 Matrix 角色名（例如 Trinity），不做批量改名。`/rename` 仍然可用。
   - 去掉 Mr.Anderson 渐变、10–20s 标题定时器和雨滴帧；标题改为静态 `Agent: <name>`，无定时器。删除 `NEO_ROLE_POOL` / `pickUnusedRole`。碰撞后缀只留给显式 `--name`（及既有 `/rename`）。README 与 help 中提及角色池或标题动画的表述已同步。

2. `a9416a91f74d8179819f0b4908876241d4251bdb`（fix: #82 P2 计数器预留失败、锁身份与默认名撞名再分配）：
   - 计数器持久化失败抛出 `DefaultNameReservationError`，不返回未预留的 Neo#N；bootstrap 在主路径和 mailbox 回退路径都会打印可见错误并以 exit 2 退出；不回退到 `neo`。
   - 锁目录为 `<mailbox-root>/.default-name-seq.lock`，含 `owner.json`（pid、`/proc` starttime、token）。活持有者（含 SIGSTOP）不会被回收。释放时仅在 dev+ino+token 全部匹配时 rename-delete。死亡/僵尸持有者会被回收。缺失 `owner.json` 使用等待方本地 1s grace，不只看目录 mtime。
   - `openMailboxIdentity` 里的默认名碰撞会再分配另一个 Neo#N，不会静默变成 Neo#N-2。`--name` 仍走后缀。resume 保留旧名。
