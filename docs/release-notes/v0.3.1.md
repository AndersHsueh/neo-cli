# v0.3.1

> 2026-10-26 · 剧情层：**会话代号 + Agent 标题动画**（含 `--resume` 真续接修复）
> 上游版本 v0.3.0

## 背景

v0.3.0 把底部状态条和输入框做出来了，接下来是「剧情感」：每个会话应该像 Matrix 里的一个角色，
顶线显示 `Agent: <代号>`；如果代号是 `neo`，标题在 `Mr.Anderson` 与绿色的 `N E O` 之间随时间切换。

在做人名之前，先修了它依赖的地基：**`--resume` 必须真续接同一个 session-id**。旧实现会新开
session-id 只把消息灌进去，导致恢复后的会话没有旧名字、信箱身份也换了——那人名池和「恢复 trinity
还是 trinity」就无从谈起。这一版把 resume 语义一起定死并交付。

## 变化

### 一、`--resume` 真续接（commit `eb19481`）

- `--resume si-123` 沿用被恢复会话的 **session-id / 会话文件 / 信箱身份**，不再 fork 新文件；
- 因此名字、inbox、outstanding、delegation 台账一起恢复；交互 `/resume` 也改为 `mailbox.adopt()`
  接管目标身份（保留目标名字/inbox，退役当前身份）；
- **活/死判定**（用户裁决）：running = `.alive` + pid 存活 + 心跳 ≤ `deadAfterMs`（默认 120s）；
  pid 已死或心跳 >120s（事件循环卡死/机器休眠）→ 视为已死，**立刻回收残留锁**恢复，不等 120s；
- 运行中的会话：`--resume`/`/resume` 拒绝（CLI exit 2）；`--resume last` 跳过；
  `/resume` 候选与 `--sessions` 都不列出（`--sessions` 只加一行「另有 N 个运行中会话未列出（/peers 查看）」）；
- `--resume si-123 --name X` 覆盖旧名；旧会话 cwd 与当前目录不同时保持当前目录运行并提示；
- 缺失/全部运行中不再静默新开会话，直接报错退出。

### 二、随机会话代号

- 角色池固定 12 个（顺序即候选序）：
  `neo · Trinity · Morpheus · Cypher · Niobe · Seraph · Oracle · Switch · Tank · Link · Ghost · Keymaker`。
- 交互 TTY 启动：
  - `--name` 显式 → 沿用现有语义（撞名 `pickUniqueName` 后缀）；
  - resume 有旧名 → 保留旧名，绝不随机；
  - 否则从池中随机取「未被存活会话占用」的名字；撞名**换下一个随机候选**，不加后缀；
  - 池全被存活会话占用 → 随机角色 + `pickUniqueName` 后缀（如 `Trinity-2`）。
- mailbox 初始化失败：本地仍选池内随机名，**只用于标题显示**；不落盘、不参与寻址。
- `/rename` 语义不变；改名后顶线立即同步。
- `neo` 是普通名字：寻址、`send_message`、`list_peers` 都用 `neo`，无特殊分支。
- 顺带修：`resolvePeer` 同名多命中时**优先 running**（dead 残留不再遮蔽活会话，避免随机名撞上
  dead profile 的名字后 `ambiguous_target`）。

### 三、Agent 标题 + Neo 动画

- 顶线从 `neo · <cwd>` 改为 `Agent: <显示名>`；`Agent:` 固定 dim；
- 名字 = `neo`（含 `/rename neo`、`--name neo`）：
  - 开局 `Agent: Mr.Anderson`（dim）；
  - 每 **10–20 秒**随机切换一次，在 `Mr.Anderson` ↔ `N E O` 之间往复；
  - 切到 `N E O` 用 Matrix 绿（#00FF41）；
  - 每次切换前 **3 帧 ×80ms 字符雨**（片假名/数字逐位收敛，每帧显示宽度 = 目标文本宽度）；
- busy 照常追加 ` · 运行中`；`topRule` 的宽度/截断逻辑不变；只重画帧，不动输入状态/光标；
- timer 全部 `unref`，由 `Composer.start/stop` 统一启停；`/rename` 离开 `neo` 立即停止动画。

## 已知边界

- 动画只对**名字恰好为 `neo`** 生效；其他角色名恒定 dim。
- 字符雨为 3 帧、固定 80ms；不做可配置。
- 不做 OSC 终端标题（tab 标题）同步，只做 TUI 顶线。
- dead 会话的名字仍保留在 `/peers` 里（直到 TTL 清理）；只是**寻址时优先 running**。
- mailbox 失败时的本地随机名不落盘，重启会换一个。
- `!cmd` 长子进程 Ctrl+C 的自动断言、PTY Screen 的 DECAWM 模拟仍留后续版本。
- 动画/颜色在真实终端的观感需要人工冒烟（PTY 只能断言文本；绿色 ANSI 由单测验）。

## 升级注意

- 版本号双源 bump 到 `0.3.1`；无配置变更。
- 顶线标题格式变化：`neo · <cwd>` → `Agent: <会话名>`；cwd 不再显示在顶线。
- `--resume` 语义变化：从 v0.3.0 的「新 session-id + 灌消息」改为「原 session-id 真续接」；
  运行中的会话不再允许恢复/列出。
- `--resume <id> --name X` 会修改被恢复会话的名字；不传 `--name` 则保留旧名。
