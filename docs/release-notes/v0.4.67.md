# v0.4.67 — 提示词三档选档核心（未接线，issue #20）

## 背景

issue #20 的核心交付之一：系统提示词按模型窗口分三档（full / standard / mini）。大窗口模型吃完整版，小窗口模型吃精简版，避免「一套提示词打天下」——小窗口被提示词挤占、大窗口又浪费。本版先交付**选档核心**，暂不接入运行时（运行时行为不变）。

## 改动

- 新增 `src/prompt/tiers.ts`：三档核心正文，由 bot-comments 源文件脚本生成并**逐字内嵌**（防手抄漂移）
- 新增 `src/prompt/render.ts`（38 行）：会话名清洗与渲染、子代理身份句（只换首句）
- 新增 `src/prompt/select.ts`（144 行）：按有效窗口与**完整系统开销**选「放得下的最大档」；default/未证实窗口一律 mini（宁小勿爆）
- 新增 `src/prompt/tokens.ts`（28 行）：系统开销估计——含工具 schema、封装与 20% 余量，明确标注为估计值
