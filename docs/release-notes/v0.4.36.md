# v0.4.36 — nextActive 复合参数 SGR 的 reset 语义

## 问题

`nextActive` 只把整串参数等于 `"0"` 当成 reset。`\x1b[31;0m`（先红再 reset）被当成普通上色追加，折行后下一行错误染色。

「参数里有 0 就整体清空」也不对：`\x1b[0;31m`（先 reset 再红）会丢掉 `31`，下一行丢色。

## 改动

- `src/tui/ansi.ts`：`nextActive` 按分号拆参数逐个走；`0`/空参数清空已累积，其后参数继续累积
- `tests/tui-frame.test.ts`：A1k 覆盖 reset 结尾 / 纯 reset 复合 / reset 开头 / 非 0 复合
