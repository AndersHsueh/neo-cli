# v0.4.55 — TUI 状态行左侧显示版本号

## 背景

TUI 状态行有 model、ctx 等字段，但看不出当前跑的是哪个版本的 neo——排查问题、对照 release notes 时都要另外查。本版把版本号摆到状态行最左。

## 改动

- `src/tui/status.ts`：状态行最左新增 `v<version>` 字段
- `src/cli/version.ts`：version 从 package.json 读取，**不引入第二份常量**（版本号双源约定不破坏）
- 优先级取舍：version 与 model 同为 priority 100，但 version **不保底**——窄屏时先丢 version 再截 model，保证模型名与 ctx 始终可读

## 验证

- `tests/tui-status.test.ts`：重写断言（69 行改动）；`tests/tier-visual.test.ts`、`tests/tui-composer.test.ts` 各补 1 处
- 依据说明：本篇依据提交 `cc131d5` 的完整消息与 diff 撰写；`docs/evidence/` 无本版本证据文件
