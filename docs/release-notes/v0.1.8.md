## 新增

### 行内选择组件 `select<T>`（`src/ui/select.ts`）

↑↓ 移动、回车确认、esc 取消的行内选择器。只重绘自己的 N 行块（`\x1b[{n}A` + `\x1b[2K`），进出前后主流输出保持线性 append-only；终态定格在 scrollback（确认 ❯ 留在所选项、取消全变暗），不擦除。

- 纯状态机 `reduce()` 导出供测试（文本 oracle）：clamp 不循环、滚动窗口跟随 cursor、viewport = min(N, 10)。
- 依赖全注入（router/out/columns/asker/clearLine），bun test 不碰真实 TTY；非 TTY 回退数字问答，`-p`/管道行为与 v0.1.5 一致。
- CJK 安全的宽度感知截断（复用 `displayWidth`）；resize 触发全块重画。

### `/resume` 无参 → ↑↓ 选择会话

替换原「看列表 → 记数字 → 输入 → 回车」四步操作。hint 显示轮数与模型，esc 取消语义不变。

### `/model` 无参 → 服务端模型可选

原「只列不选」补齐：当前模型标「当前」并定位光标，选中即切换（与显式 `/model <id>` 同一收尾，系统提示词同步 noteModelChange）。获取失败维持错误输出，不进选择器。

### `/tier` `/provider` `/mode` 无参 → 全部可选（PRD §0 预言兑现）

「后续一行调用的事」成真，三个命令各以一小步接入选择器：

- `/tier`：hint = 各档位生效路由（describeRoute），选中走 `applyTier` + `noteModelChange`，降级提示保留；顺带给 select 补了 hint 截断（长路由描述不破坏 C6 不折行）。
- `/provider`：未接入的类型标「未接入」，选中走 `switchProvider`——错误语义与显式 `/provider <name>` 完全一致，不另设禁用态。
- `/mode`：hint = 权限模式说明，选中即 `agent.mode`。
- 三者当前项均标「当前」+ initial 定位；esc 取消；非 TTY 维持原纯列表（C8）。

## 修复

- **热键系统从未生效过的存量 bug**（`src/hotkeys.ts`）：bun 与 node 都把 keypress 事件发在 stdin 而非 readline 实例上，attach 原来挂错对象——生产环境 ESC 取消（运行中打断）从未生效；且回车键名是 `return` 不是 `enter`，enter 映射从未命中。已修：attach 监听 input 流、mapKey 认 `return` 别名、测试 fake 对齐真实事件路径。M0 探针意外发现。
- select 期间 Ctrl+C = 取消选择，不再武装双击退出（SIGINT 经 onActiveChange 协调）。
- select 存续期间 readline 的 line 事件一律丢弃（bun 实证：回车会把行缓冲残留作为 line 事件发出，可能被当成命令入队）；select 结束清理行缓冲（`rl.line` 赋空 + `_refreshLine`），提示符无残留。
- bun 事件顺序分歧：同一毫秒内 bun 按 line → 残留 keypress 派发（node 反序），导致 select 打开即被「提交命令的那次回车」自动确认第一条。修复：打开后 50ms 宽限窗，窗内按键视为残留忽略（`graceMs` 可注入）。
- `console.ts` 的 `choose()` 删除（唯一调用方已迁移），组件唯一性达成（C14）。
