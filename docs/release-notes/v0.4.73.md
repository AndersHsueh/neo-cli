# v0.4.73 — 超预算提示去重闸门钉死测试（issue #20）

## 背景

审核 v0.4.72 发现一个测试缺口：超预算提示「同状态只说一次」的去重**没有被任何测试钉住**——把去重逻辑删掉，单测与 PTY S22c 依然全绿（S22c 只有一次启动，触发不了重复）。而现实流程里 rename、invalidate、切档、追加项目记忆都会让 PromptManager 重算并回调，没有去重会把同一条提示说 4 次。本版把去重抽成可测的纯函数并钉死。

## 改动

- `src/bootDiagnostics.ts`：把闸门与决策抽成 `makeOverBudgetGate` / `makeOverBudgetReporter`（纯函数，注入 sink）；`src/index.ts` 只剩接线
- `tests/boot-noise.test.ts`：补 9 个用例，覆盖——fits 不说、同状态只说一次、模型/窗口变了算新事实、非交互绝不写 TUI、启动块未输出时排队、取走即清空
- **变异验证**：7 个变异（去闸门 / 非交互写 TUI / 不排队 / fits 也说 / 取走不清空 / 构造时固定模型等）逐个确认测试变红——去重逻辑从此有测试守着
- **运行时行为不变**：五个窗口下请求体（system + tools + 字段）与 v0.4.71 逐字节相同，`-p` 的 stdout / stderr 也相同
