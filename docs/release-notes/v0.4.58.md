# v0.4.58 — 会话级 todo_write 待办清单（issue #10）

## 背景

长任务跨多轮推进时，模型没有一个结构化的待办清单来维持进度——上下文压缩后任务状态容易丢。本版加入 TodoWrite 式的会话待办。

## 改动

- 新增 `src/tools/todo.ts`（201 行）：`todo_write` 工具，语义为**整表替换**——每次提交完整清单，未提交项视为删除；同时最多一项 `in_progress`
- 状态机：`pending / in_progress / completed / cancelled`
- `src/cli/commands.ts`：`/todos` 命令查看清单；`src/tui/status.ts`：状态条显示 `✓n/m` 进度
- `src/session.ts`：清单持久化进 SessionMeta，**上下文压缩后进度仍在**
- `src/system-prompt.ts`：系统提示词登记工具用法
