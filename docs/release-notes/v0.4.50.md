# v0.4.50 — 模型五项能力字段 + `/models` 解析（issue #5 P1）

## 背景

issue #5 的目标：让 neo 把模型的真实能力（上下文窗口、输出上限、视觉、工具、推理）摸清并展示出来。本版是五步交付的第一步（P1）：**先有数据结构**，把能力字段定义下来，并从 `GET /models` 的响应里解析；展示（P2）、写回（P3）、切模型刷新（P4）留待后续版本。

## 改动

- `src/env/types.ts` / `src/config.ts`：`ModelContextInfo` 扩展，新增 `vision` / `tools` / `reasoning` 能力位；settings 支持手工填写这些字段
- `src/env/modelWindows.ts`：从 `GET /models` 响应解析 `max_output` 与能力标志位
- 口径：**用户在 settings.json 手工填写的值优先**，解析结果只填空字段
- 本步刻意不做的事（后续版本补）：`/context` UI 展示、撞墙/首次使用时的探测写回、沙箱
- 同步修正 package.json 版本漂移：tag 已到 v0.4.49 而 package.json 停在 0.4.33，本版对齐到 0.4.50

## 验证
