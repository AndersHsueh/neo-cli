## 变更

### #62 Ctrl+G 用外部编辑器撰写提示词

输入框按 `Ctrl+G` → 当前内容写进临时文件 → 调起 `$VISUAL`（优先）/`$EDITOR` → 退出后读回回填输入框，光标在末尾。写长需求、粘贴改写大段日志时不必逐行敲。

- 新增 `src/editor.ts`：编辑器解析（按引号切分命令）、临时文件、spawn、读回、失败收敛成可读原因。
- `src/tui/keys.ts`：`Ctrl+G` → `ctrl-g` 动作。
- `src/tui/composer.ts`：挂起 TUI → 跑编辑器 → 恢复 → 回填；失败/取消只给一句提示，**原草稿原样保留**。
- 命令不经 shell 解释（argv 直传 spawn）：`EDITOR="code --wait"` 可用，但不会引入命令注入面。临时文件用完即删。

### #56 Notification hook

新增第四个 hooks 事件：等审批（`permission_prompt`）或轮次结束（`turn_end`）时发通知，用户自接 `osascript` / `notify-send`。

- matcher 匹配的是**触发原因**而非工具名（`matchReason` 与 `matchTool` 分开）。
- Notification **恒不阻断**（没有模型要喂回原因，失败只进诊断）。
- `permission_prompt` 在审批框弹出**之前**发；`turn_end` 通知先于 TurnEnd 发。
- plan 模式与既有 hooks 同口径跳过；子代理不触发。

### #61 `/btw` 旁支提问

`/btw <问题>` 基于当前会话已有上下文回答一个独立问题，**不入历史、不调工具、不打断主轮次**。主任务跑着时插一句「刚才那个配置文件叫什么」，答案拿到了，主任务的上下文没被污染。

- `src/agent/loop.ts` 新增 `Agent.askSide()`：请求走 `this.messages` 的**快照**（`[...this.messages]`，过滤召回注入的临时消息），**绝不 push 回主 messages** —— 它是活引用，push 会污染主上下文并随 session 落盘；`tools` 传空数组；用量走 `recordUsage` 显式记账（否则 `/cost` 少算）。
- `src/cli/commands.ts` 新增 `case "btw"`：缺参数给用法提示不发请求；oneshot（`-p`）模式不可用；失败给可读原因；成功按 markdown 渲染。
- `src/input/commands.ts` 登记 `btw`（补全可见）。
