# v0.4.40 — AGENTS.md 区块标记乱序不再非幂等膨胀

## 问题

`composeAgentsContent` 只检查 START/END 是否存在，不检查顺序。END 在 START 之前时，`slice` 会再插一对标记，每次 `/init` 让 AGENTS.md 增长约 900 字节。

## 改动

- `src/memory/agMd.ts`：要求 `end > start`；乱序/残缺时摘掉残留标记行再追加干净区块
- `tests/memory-agmd.test.ts`：8 条覆盖 null/空/无标记/正常/乱序/残缺

## 验证

- `bun test`：1144 pass / 0 fail / 71 files
- `bunx tsc --noEmit`：exit 0
