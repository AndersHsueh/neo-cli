# v0.4.37 — layoutBuffer 断点后连续空格不产生纯空格行

## 问题

`layoutBuffer` / `wrapSegment` 词边界折行后只跳过断点那一个空格，紧随其后的连续空格变成下一行内容，于是 `"ab   cd"`（宽 3）折出 `["ab ", "  ", "cd"]`：输入框凭空多一行空白，↑↓ 多跳一行。

## 改动

- `src/tui/buffer.ts`：词边界折行且断点前已有非空白时，丢弃断点后的连续空格；纯空格行（B1i）不断点前无内容，原样保留
- `tests/tui-buffer.test.ts`：B1f2

## 验证

- `bun test tests/tui-buffer.test.ts`：51 pass / 0 fail
- 全量：除既有 F2g（与本改无关，failTool 行首空格期望过时）外通过
- `bunx tsc --noEmit`：exit 0
