# v0.4.63 — 托管 git worktree（issue #9）

## 背景

并行任务（比如本篇 release notes 的补齐工作）需要文件级隔离，手工 `git worktree add` 的路径管理、分支命名、清理都容易出错。本版让 neo 自己管理 worktree。

## 改动

- 新增 `src/worktree.ts`（471 行）：
  - `neo --worktree/-w <name>`：在 `.neo/worktrees/<name>` 创建或复用 worktree（分支 `neo/<name>`），整个会话在其中运行；失败时给可读报错并回滚
  - `/worktree list|remove`：只管理 **neo 自己创建的** worktree
- 删除保护：worktree 有脏改动或未跟踪文件时拒绝删除，除非 `--force` 加确认；当前所在 worktree（含子目录、symlink 别名进入的情况）**永不删除**
- README/help 文档说明路径、.gitignore 与 `/peers` 配合用法
- 定位说明：这是**文件隔离，不是沙箱**——安全边界不靠它
