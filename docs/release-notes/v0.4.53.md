# v0.4.53 — `/model` 切换后刷新模型能力（issue #5 P4，收官）

## 背景

P1–P3 之后能力链路还差最后一环：用户 `/model` 切到另一个模型，展示与写回的还是旧模型的能力。本版（P4）把切换后的刷新补上，issue #5 的五项能力交付至此闭环。

## 改动

- `src/cli/commands.ts`：`/model`、`/provider`、`/tier` 成功后触发刷新
- `src/env/modelWindows.ts`：先**同步**应用窗口（本轮请求就用对的值），再**异步**跑 `detectAndRecordModelWindow` 探测
- 竞态处理：用户连续切换时，**丢弃上一次未完成的探测结果**，只认最后一次

## 验证

- `tests/model-switch-refresh.test.ts`：新增 338 行，覆盖切换刷新与竞态丢弃
