## 变更

### #50 `/drive --judge`：模型判断完成条件

- 命令：`/drive --judge "<完成标准>" -- <提示>`；可与检查命令同给。
- **检查命令仍是硬条件**：exit 0 → 已完成，来源 **已验证**（verified）。
- 检查未过或没有检查命令时问模型判断；达成 → 停，来源 **模型判断**（model），
  结束文案**禁止**出现「已验证/通过验证」（K1/K2 作为回归锚点）。
- judge 抛错/超时/输出不可解析 = **未达成**；连续 2 次暂停（`JUDGE_FAILURE_LIMIT`）。
- judge 输入只取**本轮**工具输出（按 `turnStats.toolCalls` 切片）；输出超 2000 字符截断标注。
- judge 请求经 `Agent.recordUsage` 计入 `/cost`（与 compact 摘要记账同口径）。

### #51 `-p` 无人值守长跑

```bash
neo -p "把测试修到全绿" --drive "bun test" --max 5 --max-minutes 30 -y
```

- **三层不同轴的上限，不新增 max-turns**：
  `max_tool_iterations`（单轮内工具迭代，默认 80）× `--max N`（驱动轮次，默认 5、1–20）
  × `--max-minutes M`（墙钟，默认 30、1–240）。
- **必须显式 `-y`**：缺了 exit 2 且一次模型请求都不发；启动 stderr 警告全自动批准。
- 退出码：达成 0（stderr 摘要标 `source=verified|model`）；未达成（exhausted / idle-stop / timeout）1；
  SIGINT 130；用法错误 2。
- 结束 stderr 一行：`[drive] status=… source=… rounds=… elapsed=…s`；stdout 保持 `-p` 现有风格。
- `idle-stop`（连续空转）在 `-p` 下同样生效：无人可问，直接停、exit 1，不原地烧轮次。
- 所有退出路径走 `cleanupEphemeralResources()`（#40）；墙钟只在轮间检查（PRD 写明，不硬杀）。
