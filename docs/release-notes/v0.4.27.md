# v0.4.27 —— CDATA 字面量语义；跨边界不再拼实体

## 为什么

`decodeXml` 先脱 CDATA 壳再整体解实体，两处真缺陷：

1. `<![CDATA[a &amp; b]]>` 被解成 `a & b`（违反 CDATA 字面量语义）
2. `<![CDATA[&am]]>p;` 脱壳后拼成 `&amp;` 再解成 `&`（凭空造内容）

## 改了什么

CDATA 与实体同一正则扫描；段用私用区占位符穿过后续处理。
`stripTags`：段内**剥标签、不解实体**（Bing 摘要高亮去掉，`&amp;` 保留字面量）。

## 测试

全量 1115 pass / 0 fail；`tsc --noEmit` 干净。
