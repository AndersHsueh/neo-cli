## 变更

### 行为修复

- **会话袋里的信箱状态改为实时值**（v0.4.88 未做第 1 条）：`heartbeatTick`、`mailboxClosed` 从 `bootstrap()` 的局部 `let` 移到共享对象 `SharedMut` 上，`closeMailbox()` 与心跳装配直接读写 `s.*`，`Object.assign` 不再拷快照。之前 `closeMailbox()` 之后读方从会话袋读到的仍是启动时的值。测试 `tests/bootstrap-live-state.test.ts` L1/L2 先红后绿。
- **输入历史 1000 条上限**（第 4 条）：`InputHistory` 超过 `INPUT_HISTORY_LIMIT = 1000` 时丢最旧的，构造时只保留最近 1000 条（不改调用方数组）。上限来自 `docs/v0.3.0-tui-prd[done].md` 审查项「history 加 1000 条上限」，此前常量从未接入。历史只在进程内，不落盘，不涉及持久化；readline 降级路径的 `historySize: 200` 不变。`tests/tui-buffer.test.ts` B4j / B4k 先红后绿。
- **粘贴图片 chip 编号不再是 `NaN`**（拆分回归，不在 9 条内）：v0.4.87 拆分把 `pasteTextCounter = 0; // 注释` 与下一行 `pasteImageCounter = 0;` 并成一行，第二条语句落进行尾注释、从未执行，首张粘贴 / 拖入图片的 chip 编号为 `NaN`。已还原为拆分前（`68bd217`）的分行。`tests/bootstrap-live-state.test.ts` L3 先红后绿。全 `src` 已搜「语句被挤进注释」的同类形态，没有第二处。

以上行为均已有既有 PRD 规定（`docs/v0.3.0-tui-prd[done].md`、`docs/paste-enhancement-prd[done].md`），本版是让实现回到规格，不新开 PRD。
