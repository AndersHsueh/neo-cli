# v0.4.34 — 裸 ESC 零宽且不残留

## 问题

`tokenizeAnsi` / `stripAnsi` / `displayWidth` 的正则只认「ESC + 合法转义」（CSI / OSC / 两字符）。裸 ESC（后面是普通字符或已到结尾）落在覆盖范围外：

- `tokenizeAnsi` 把它保留成零宽 SGR token → `truncateAnsi` / `wrapAnsi` 行尾可残留裸 ESC，终端进入转义状态吞后续输出
- `stripAnsi` 剥不掉
- `displayWidth` 的 `ANSI_ESCAPE` 同样剥不掉（与截断快路径叠加：修宽度后快路径会原样返回带 ESC 的原文）

## 改动

- `src/tui/ansi.ts`：`tokenizeAnsi` 裸 ESC 直接丢弃；`stripAnsi` 末尾补剥裸 ESC；`truncateAnsi` 快路径要求 `!text.includes("\x1b")`
- `src/ui/theme.ts`：`ANSI_ESCAPE` 追加裸 `\x1b` 备选
- `tests/tui-frame.test.ts`：A1i 覆盖 displayWidth / strip / tokenize / truncate / wrap
