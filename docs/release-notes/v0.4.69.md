# v0.4.69 — 子代理提示词三档：默认 mini + 按窗口升级（issue #20）

## 背景

主代理接入三档后（v0.4.68），子代理还吃固定提示词。子代理模型窗口可能比主代理小得多，主代理的档位不适用于它。本版让子代理按**自己的**窗口选档。

## 改动

- 新增 `src/prompt/subagent.ts`（80 行）：子代理改用三档核心，**默认 mini**
- 身份句：「你是 ${主会话名} 派出的子代理」——取自当前会话名，随 rename 更新
- 子代理按**它自己的**模型窗口与来源选档：重新解析窗口，不复用主代理的窗口
- `task` 工具新增 `prompt_tier` 参数（auto/standard/full）；高后果措辞的任务自动至少 standard
- 控制边界：要求的档位在子模型窗口放不下时**交回主代理**，不降低控制要求；升级不增加权限，也不等于用户批准
- 子代理不能直接问用户：缺批准时向主代理报告并停止
