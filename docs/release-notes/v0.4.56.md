# v0.4.56 — 连续只读工具并行调用（issue #11）

## 背景

此前工具一律串行执行：模型一次发多个只读调用（如同时 glob + grep + read_file）时，neo 逐个跑，纯 I/O 等待被拉长。本版对**连续的只读工具**放开并行。

## 改动

- `src/agent/loop.ts`：连续只读工具段允许 `parallel_tool_calls` 并行执行
- 只读白名单：`read_file` / `list_dir` / `glob` / `grep` / `web_fetch` / `web_search` / `wiki_search`
- **写操作与 shell 仍是串行屏障**：一旦遇到写工具，并行段结束
- `src/llm.ts` / `src/config.ts` / `src/tools/types.ts`：请求体与配置支持该字段；settings.example.json 补示例
- 兼容性兜底：**拒绝该字段的瘦网关**自动降级为串行执行该请求，不崩溃
