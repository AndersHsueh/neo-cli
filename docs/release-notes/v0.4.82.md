## 修复

- **`/rewind` 只列用户轮次（#42）**：跨会话消息 / 状态通知 / `/loop`·`/drive` 注入不再进列表与编号；
  内部仍记账 —— 回滚用户轮次时，其后自动轮产生的文件检查点一并恢复；旧会话记录无来源字段按用户轮次兼容。
- **`/rewind` 在 `/compact` 之后失效（#39）**：压缩把较早历史换成摘要后，按被删头段条数平移
  `messagesBefore`；轮次起点落在被压缩区间的 **clamp 到摘要位置**并在回滚时给出说明（逐字原文不可恢复）。
- **`-p` / 非交互路径不回收后台资源（#40）**：抽 `cleanupEphemeral()` 唯一清理入口
  （顺序：驱动 → 子进程（子代理/后台 shell/LSP）→ MCP → 信箱），`shutdown()` / `-p` /
  `args.rest` 非 TTY 三条路径共用；`tdzSafe()` 处理 `loopScheduler`/`drive` 在 `-p` 路径上的 TDZ。
- **`-p` 下斜杠命令口径（#41）**：行首已登记命令（含别名）明确提示「只能在交互模式使用」+ 退出码 2，
  不再把整串静默发给模型；`/notacommand hi`、「请执行 /help」这类普通文本照常发送。

## 增强

- **LSP 扩展（#43，来源 #23 非目标）**：`lsp` 工具新增 `workspaceSymbol`、`callHierarchy`
  （prepare + incoming/outgoing 两段式，item 原样回传）、`completion`；initialize capabilities 扩展；
  `onMessage` 应答 server→client 请求（`workspace/configuration` 等，否则 pyright 一类会挂）；
  `line` 由 required 改可选；列表类结果统一「N 条」截断口径。
- **MCP 旧式 SSE 传输（#44，来源 #29 非目标）**：新增 `SseRpc`（GET 长连接 + 首事件 `event: endpoint`
  握手 + POST 202 + 常驻读流 + pending Map + 断流立即 failAll）；`transport: "sse"` 配置；
  与 streamable HTTP 共用 SSE 块解析；不重连（与 #29 主项同口径）。
- **后台子代理任务落盘（#45，来源 #16 非目标）**：任务表纯数据快照写入 session meta
  （上限 20 条 / 单条结果 2k 字符）；`--resume` 后加载为只读历史，`running` 一律标 `interrupted`，
  `/tasks` 可见「中断」；发起即落盘，`shutdown()` 前再同步一次。
