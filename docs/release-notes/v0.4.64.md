# v0.4.64 — 生命周期 hooks（issue #3）

## 背景

团队想在工具调用前后、turn 结束时挂自己的脚本（审计、通知、自动格式化）。本版（issue #3）提供项目级生命周期 hooks。

## 改动

- 新增 `src/hooks/`：`runner.ts`（302 行）、`types.ts`（283 行）、`index.ts`
- 配置：`settings.hooks` 支持 `PreToolUse` / `PostToolUse` / `TurnEnd`
- 协议：stdin JSON 传入调用上下文；支持 matcher 过滤、超时（超时按进程组 kill）、`onFailure: continue|block`
- **定位边界：hooks 是生命周期脚本，不是权限系统**——审批仍然先行，Pre 只能 block，不能放行
- plan/review 运行不触发 hooks；子代理只有 Pre/Post，没有 TurnEnd
- 语义细节：被拒绝或被 Pre block 的调用跳过 Post；`consecutiveFailures` 对未执行的调用保持中性；真实失败照常计数
- `/hooks` 命令查看；README 196 行文档；settings.example.json 补示例
