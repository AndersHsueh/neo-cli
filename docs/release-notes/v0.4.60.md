# v0.4.60 — 交互式 /plan 规划工作流（issue #14）

## 背景

此前的 plan 模式（`/mode plan`、`--plan`）只是一道只读闸门：模型不能写盘，但没有「先出结构化计划、人确认后再动手」的正式流程。本版（issue #14）把规划做成**独立的交互式会话阶段**。

## 改动

- 新增 `src/agent/plan-mode.ts`（284 行）与 `src/tools/plan.ts`（98 行）：规划会话流程——先澄清范围与取舍，模型用 `submit_plan` 提交结构化计划（步骤 / 风险 / 涉及文件），**用户确认或要求修改后**才恢复写盘与执行
- `src/agent/loop.ts`：工具循环接入规划态；规划态下工具清单收窄为只读集合
- `src/cli/commands.ts`：命令面接入；`src/tui/status.ts`：状态条显示规划态
- 边界：`/mode plan` 与 `--plan` **保持纯只读闸门不变**，不进入这套确认工作流——两套机制语义不同，不混用
