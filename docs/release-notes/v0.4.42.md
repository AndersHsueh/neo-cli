# v0.4.42 — 预算提示剩余次数把本次请求算在内

## 问题

`budgetMessage` 用 `remaining = max - attempt`。`attempt` 是第几次请求（`iter + 1`），本次请求尚未消耗预算，首轮就报「剩余 79/80」、末轮报「仅剩 0 次」，模型容易提前收手。

## 改动

- `src/agent/steer.ts`：`remaining = max - attempt + 1`
- `tests/agent-policy.test.ts`：首轮剩余=上限、末轮剩余=1

## 验证

- `bun test`：1147 pass / 0 fail
- `bunx tsc --noEmit`：exit 0
