# v0.4.68 — 提示词选档接入主代理，修复 #19（issue #20）

## 背景

v0.4.67 的选档核心还是孤岛。本版把它接入主代理运行时：新增 PromptManager 作为系统提示词**唯一渲染入口**，顺带修复 #19（rename 后身份句不更新）。

## 改动

- 新增 `src/prompt/manager.ts`（116 行）：PromptManager 持有会话名与项目记忆，按当前窗口与完整开销**现算**档位
- `src/index.ts`：三处直接写 `messages[0]` 的位置改走 manager——修复「工具注册后重建」与「追加项目记忆」互相覆盖的问题
- `src/agent/loop.ts`：Agent.send 在**请求边界**重渲染——探针完成、切模型、超限校正、rename 都在下一轮生效，不改写流式中的请求
- rename 后系统提示词身份句随之更新（**fixes #19**）；旧人格正文由三档核心取代，`buildSystemPrompt` 只产出动态块
- 窗口来源语义：用户显式配置 vs 模板/内置 200K 兜底分开记——兜底记为 `default`，不当作已证实窗口升档
- 开销估计按字符类别计，避免把工具 schema 按 CJK 比例高估数倍
- settings 新增 `system_prompt` 段；`/context` 展示所选档位、预算与原因
