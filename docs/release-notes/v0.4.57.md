# v0.4.57 — 斜杠 `/技能名` 直接调用技能（issue #13）

## 背景

技能此前只能靠模型自主决定加载（或 /skills 查看），用户想明确触发某个技能时没有直接入口。本版支持用户直接敲 `/技能名 [参数]` 调用。

## 改动

- `src/skills.ts`：斜杠技能解析——`/skill-name args` 入队一个 turn，把 SKILL.md 正文注入（`$ARGUMENTS` 替换为用户参数，无参数时替换尾部的 `用户参数` 占位）
- `src/cli/commands.ts`：CLI 命令面接入
- 命名冲突：**内置命令优先**，斜杠技能让位并给提示
- `/skills` 保持只读（约束 16 不变）
