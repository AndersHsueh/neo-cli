## 变更

### #60 ACP v1 服务端

`neo acp` 提供 stdio ACP v1 服务端，与 TUI / `-p` 互斥，stdout 只写协议 NDJSON、诊断走 stderr。实现 initialize、session/new、文本 prompt、流式消息、工具事件与文件 diff、编辑器权限 RPC、session/cancel，以及 help / README 的 Zed 配置。复审修复包括取消后迟到批准、权限模式与模型配置同源、dispose 回收后台 shell、MCP 握手中断连回收、已作答轮不误报迭代上限。

提交：`d833a83`、`d26eda1`、`443b660`、`5953f41`、`1ad55e7`、`c179046`、`bccc828`、`dfc1449`；对应红测与 simplify 同属本次 37 笔提交。

### #80 ACP 后续能力与取消竞态

`6363109` 增加 available_commands_update、session/set_mode（ask / auto-edit / auto-all / plan）、session/load（复用会话恢复路径，仍一进程一 session）、usage_update。`67757f3` / `1898d87` 在入站拆包时同步落取消闩，EOF / 超长行同样落闩，写盘前再检查，取消后迟到的 allow_once 不再写盘。

### #75 进程组回收与兼容性变化

`08e2062` / `b96ad2f`：后台 shell 按进程组终止，先 SIGTERM 后按需 SIGKILL；MCP 断连回收已握手未注册连接。`49f39ae` / `eb963a0`：信号退出前回收脱组 shell，TUI 清理复用 reapSession。

升级前请注意：
1. **nohup 后台服务仍会随 neo 退出被杀**。受 neo 管理的后台 shell 按进程组回收；需长期驻留的服务请用系统服务管理器。取消当前前台轮次不等同于取消全部后台任务。
2. **模型拉起的进程没有控制终端**。POSIX 上 detached/setsid 自成进程组，工具输出使用 pipe；sudo / ssh 需要交互密码提示时会失败，应在 neo 外部终端完成交互认证。
3. **ACP 收到 SIGINT / SIGHUP / SIGTERM 时先 dispose 再退出**，先回收受 neo 管理的在途 shell、后台 shell 与 MCP 连接，分别以 130 / 129 / 143 退出。

### #76 空闲 CPU

`206a13a`：composer 的 250ms tick 按 busy / activity / noticeText 按需启停；branch 与 ctxUsage 各自缓存 500ms，避免空闲唤醒与重复昂贵计算。mailbox 同步 readdirSync 未改异步。

### #74 / #79 输入框编辑（非 Vim）

`852c70d`：Ctrl+R 交互式反向历史检索，Enter 回填不发送、Esc 取消；Ctrl+S 单槽暂存/恢复文本、光标、粘贴 chip 和 ! shell 模式。

`aa5e0d0`：kill ring（Ctrl+Y / Alt+Y）、撤销（Ctrl+_）、统一词边界（字母数字段 / CJK 段 / 标点）与词级编辑、Ctrl+P/N、清空后草稿召回、空框 ? 帮助、模式强调色、Shift+Tab / Alt+M 循环权限模式、排队内容收回、Ctrl+X Ctrl+S 立即发送、句中 / 补全、提交剥不可见 Unicode。`5eb6e82` 修复普通 Backspace/Delete 不进 kill ring；有意的 kill 操作仍进环。Ctrl+Enter 保持换行，明确不做 Vim。

### #53 轮末按需后台 wiki 维护

`7ad6d84` / `00d8173`：只接交互 REPL 轮末，不接 -p / ACP。remember 后做代码侧 lint；只有本阶段落页上的 broken / nosummary / nostamp 才派 fast worker 修，lint 干净不增加维护模型调用。raw 增删独立判定：仅有快照、快照不超过 1 周且单次新增 ≤10 份时自动增量；无快照、过期或超上限，每会话只提示一次手动 /ingest。

worker 在 /tasks 显示 [wiki]，不占三个用户任务名额、不注入主会话、不落 session meta。工具仅 wiki_search / wiki_write / read_file / list_dir / glob / grep；allowlist 只在传入时于 schema 与 dispatch 两层生效，既有排除表缺口留给 #84。worker 期间暂停捕获出队，重复触发合并再判；只有 worker 的 wiki_write 加锁，约 5s 超时静默放弃本轮、下一轮再判。其它失败/超时/取消只降级提示并写 wiki log，不更新快照。成功快照只记本次计划内增删，避免运行中新增 raw 被误标已编译。

**memory.auto_maintain 默认 true，false 同时关闭自动增量和 lint 收口**（README 有配置示例）；手动 /ingest 不受此开关影响。P1 同步修复：/ingest 子代理失败或中止不再 finishIngest、不记成功日志。
