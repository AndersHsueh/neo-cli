# v0.4.59 — `/last` 历史中 write/shell 工具卡片化

## 背景

`/last` 回看历史时，write_file / shell 这类有实质副作用的工具调用只显示成一行紧凑工具行，看不出写了哪个文件、跑了什么命令、效果是什么。本版给 `/last` 加多行工具卡片。

## 改动

- 新增 `src/ui/toolLine.ts`（83 行）：多行工具卡片 helper，覆盖 `write_file` / `edit_file` / `shell` / `remember` / `wiki_write`——展示路径或命令 + 效果摘要
- `src/ui/toolLog.ts`：`/last` 历史渲染接入卡片
- 顺手修复：补上缺失的 `isCardTool` / `toolCardRows` import，使改动通过 typecheck
- **实时 console 不变**：交互中仍是紧凑单行工具行，卡片只在 `/last` 回看时出现

## 验证

- 依据说明：本篇依据提交 `4707dd4` 的完整消息与 diff 撰写（该提交无新增测试文件）；`docs/evidence/` 无本版本证据文件
