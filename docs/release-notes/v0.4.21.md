# v0.4.21 —— 抽出共享实体解码；NUL 实体不再产出 U+0000

## 为什么

`&#0;` / `&#x0;` 是合法码点，`String.fromCodePoint(0)` 不抛错，但解出的
U+0000 会污染模型上下文、终端与 JSON，且肉眼不可见。v0.4.19/v0.4.20 的
越界防护漏掉了它。

同时 `codePointToString` 在 `index.ts` 与 `webSearch.ts` 各写一份，实体表
已开始漂移（`&apos;` 只有 XML 侧认）。

## 改了什么

- 新增 `src/tools/entities.ts`：`codePointToString`（`cp <= 0` 原样保留）+
  `decodeNumericEntities`
- `htmlToText` / `decodeXml` 改用共享模块；`htmlToText` 补 `&apos;`
- 测试覆盖 NUL、`&apos;` 对齐

## 测试

全量 1106 pass / 0 fail；`tsc --noEmit` 干净；`verify.sh` ALL GREEN。
