# v0.1.9

> 2026-10-19 · 次要版本：粘贴增强 M1+M2 完整交付 + compact_ctx 工具

## 新增

### 粘贴增强（PRD `docs/paste-enhancement-prd.md`，M1 + M2 全量）

**M1 长文本折叠** —— 修复存量 bug：多行粘贴被 readline 逐行提交（3 行 = 3 次独立 LLM 调用），粘贴内容含回车即误提交。

- 探针定案（PRD §7）：启用 bracketed paste（`\x1b[?2004h`），粘贴期间 line 收集不提交，paste-end 重组全文
- 含 `\n` 必折叠为 `[Pasted text #N +X lines]`（readline 行缓冲装不下换行，结构性约束）；单行 ≥300 字符折叠（`paste.fold_chars` 可配置）
- 发送时还原原文；chip 被删除 = 放弃附件；手打同款字样不误还原
- 粘贴行不污染 ↑ 历史（定向回滚）

**M2 macOS 贴图** —— Ctrl+V（Alt+V 同效）读剪贴板图片，输入框出现 `[Image #N]`，发送后模型能看到图。

- JXA 临时文件协议（PRD §7 P2 定案）：stdout 直出被 JXA 返回值污染（尾部多 `"0\n"`）、退出码不可控——改走 `writeToFileAtomically` + 文件存在性判据 + stderr 诊断
- 截图场景覆盖：Cmd+Shift+Ctrl+4 进剪贴板的是 TIFF，自动转 PNG
- `Message.content` 扩为多模态数组（OpenAI 兼容 `image_url` part）；token 估算图片按 800/张
- 附件落盘 `attachments/<sessionId>/img-N.png`，会话 JSON 存 `$ref` 指针不存 base64；`--resume` 恢复时重组，文件缺失降级 `[Image #N 已丢失]`
- 图片上限 8MB（`paste.image_max_bytes` 可配置）；剪贴板无图时 info 一行不报错

**compact_ctx 工具** —— 模型可主动请求压缩对话上下文：登记请求后在当前工具批次结束执行，保留用户目标/关键结论/改动路径，丢弃冗余工具输出。适合大范围探索后主动整理窗口。子代理排除名单同步收口（防止子代理误压主代理上下文）。

## 修复

- **mapKey 守卫顺序**：Ctrl+V 判定原写在「ctrl/meta 一律忽略」守卫之后，永远不可达——E2E 实证暴露，已修并加单测钉死
- **版本号双源漂移**：`src/index.ts` 的 VERSION 停在 0.1.5（v0.1.2 起漏更，踩坑 #8 现象），本次双源同步至 0.1.9
