# v0.4.61 — `/review` 一等公民化：git diff 审查入口（issue #12）

## 背景

代码审查此前靠用户手工组织上下文（自己贴 diff、自己说背景）。本版把 `/review` 做成一等命令：自动收集 git diff，直接开一个审查 turn。

## 改动

- 新增 `src/review.ts`（205 行）：CLI 侧 git diff 收集
  - `/review [baseline]`：可指定基线（commit/分支），缺省为默认基线
  - 工作树干净时短路（没东西可审）；未跟踪文件单独列出
  - diff 大小设上限，防止超大 diff 撑爆上下文
- `src/input/commands.ts` / `src/cli/help.ts`：命令与帮助登记
- 规划态（plan-mode）下 `/review` turn 保持只读闸门

## 验证

- `tests/review.test.ts`：新增 458 行
- 依据说明：本篇依据提交 `7d78b17` 的完整消息与 diff 撰写；`docs/evidence/` 无本版本证据文件
