# v0.4.20 —— htmlToText 补齐十六进制数字实体

## 为什么

`htmlToText`（web_fetch）只解码十进制实体 `&#(\d+);`，没有 `&#x...;` 分支；
而 `decodeXml`（web_search）两边都有。网页里 `&#x27;`（单引号）、`&#x2F;`、
`&#xA0;` 很常见，会原样漏进抓取结果。

## 改了什么

`src/tools/index.ts`：

- 在十进制分支前增加 `/&#[xX]([0-9a-fA-F]+);/g`
- `codePointToString` 增加 `raw`，越界时返回原文（与 decodeXml 对齐，
  不再把 `&#x110000;` 改写成十进制）

## 测试

- 十六进制常规解码（含中文、emoji、大小写 x）
- 越界/代理区十六进制原样保留、不抛 RangeError

全量 1102 pass / 0 fail；`tsc --noEmit` 干净。
