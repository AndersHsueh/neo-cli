# v0.1.2

> 2026-10-16 · 补丁版本：交互会话恢复

## 新增

### /resume —— 交互中恢复历史会话

此前恢复会话只能靠启动参数 `--resume`，会话进行到一半想切回另一个对话只能退出重启。现在：

```
/resume          # 列出最近 8 个会话，输序号恢复，回车取消
/resume <id>     # 按 id 片段匹配直接恢复（与 --resume 同语义）
/resume last     # 恢复最近一次
```

选择列表每行带 id、轮数、模型与**首条用户消息预览**——会话 id 是时间戳，辨识度全靠预览。恢复成功后显示该会话的「上次输入」，便于确认接上了上下文。

**行为语义：原地续写。** `/resume` 把持久化重定向到被恢复的会话文件，后续对话续写进该文件；原会话历史不丢，随时可以再 `/resume` 切回。注意这与启动参数 `--resume` 不同——后者是分叉（恢复后另起新会话文件，原文件不动）。两者是否统一，留待后续版本决定。

### NEO_SESSIONS_DIR 环境变量

会话目录注入点（与 `NEO_MEMORY_DIR` 同一惯例）：测试与 CI 可把会话读写隔离到沙箱，不再依赖 `~/.neo/sessions` 的真实路径。

## 改进

- `neo.sh` 改为按脚本自身位置解析入口，任意目录可用（此前硬编码相对路径）。
- 会话恢复的消息组装逻辑（保留当前 system、过滤历史 system）抽为 `session.ts` 的 `applyRestored()`，启动路径与 `/resume` 共用，消除重复。

## 测试

新增 `tests/resume.test.ts`（7 用例）：applyRestored 组装规则、持久化重定向、id 片段匹配、not-found。全量 264 pass / 0 fail，`tsc --noEmit` 干净。

## 升级说明

无破坏性变更。`/resume` 为纯新增命令，配置格式不变。
