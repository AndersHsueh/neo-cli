## 为什么发这一版

v0.4.93 之后合入 #69 两组提交：交互 slash `/cd` 切换会话工作目录，以及复审修复——异步 LSP 重启失败时把警告返回给用户。功能提交与发版提交分开：**本提交仅改版本元数据及文档，无新增运行时行为**，不改源码、测试、ACP 或 settings。规格见 `docs/cd-workdir-prd.md`。不宣称与 Claude Code 完全兼容。

## 变更

1. `7d38154`（feat: 交互 /cd 切换会话工作目录，#69）：
   - 只做交互 slash `/cd`，不是模型工具；`-p` 仍拒绝斜杠命令（既有 #41 行为）。本单不改 `src/acp/*`；编辑器换工作区走现有 `session/new` / `session/load`。
   - 全程不调用 `process.chdir()`，就地改会话 `cfg.cwd`。路径相对当前会话 cwd（不是 `process.cwd()`），支持 `~` 与 `~/...`（`~user` 不展开）；先 resolve 再 realpath，会话里只存规范绝对路径。
   - 无参数 `/cd` 打印当前目录，不改状态；`/cd -` 回上一根（没有则拒绝；失败的 `/cd` 不写入上一根槽）。与当前根 realpath 相同则成功并提示「已在该目录」，不做刷新。
   - 后台子代理任务正在跑、wiki worker 正在跑、或当前用户轮次 / 工具循环在进行时，拒绝换根并说明原因。`/mode plan` 与 `/plan` 规划态都允许 `/cd`。已启动的后台 shell 保持启动时快照的 cwd。
   - 成功条件含 persist `meta.cwd`：落盘失败则 cwd 与所有侧状态仍停在旧根。必做改挂（FileIndex、项目记忆 / 规则、PromptManager、MemoryBridge、CheckpointStore、mailbox）失败则全部回滚（含磁盘 meta）。
   - LSP 重启失败只警告、不回滚已成功的 cwd 切换。
   - 重建 `messages[0]` 项目记忆节（只加载新根上那一个 `AGENTS.md` / `NEO.md` / `.neo.md`，按此顺序取第一个存在的；没有则为空，不沿用旧文），不追加消息。对话历史不动。PromptManager 指纹含 `cfg.cwd`。
   - 会话文件仍在全局 `~/.neo/sessions/`，不搬家、不改 id，只更新 `meta.cwd`。`--resume` 不自动切 cwd：启动 cwd ≠ 记录 cwd 时只提示。
   - 不做目录信任名单 / 沙箱 / trusted-dirs；不实现 #63 `--add-dir` / `/add-dir`、#54 嵌套 `AGENTS.md`。未来口径：成功 `/cd` 会清除本会话已 add 的额外目录作用域。
   - settings / 已连接 MCP 进程 / `process.cwd()` / 用户 wiki / 全局技能 / 环境快照页不跟换根。不宣称 JsonlWriter 已切换（stream-json 事件里的相对路径本版本不随 `/cd` 改写）。要使用新项目的 MCP / 本地 settings，须在该目录重新启动。
   - 本单含最小目录补全（只列 prefix 所在层的子目录，跳过 `node_modules` / `.git`，不补文件），接到 Composer Tab 与 readline。
   - 不宣称与 Claude Code 完全兼容。

2. `efee7e1`（fix: /cd 异步 LSP 重启失败时把警告返回给用户，#69）：
   - 把 `changeSessionCwd` 改为 async，并在返回前 `await restartLsp`。同步抛错与 Promise rejection 都进入 `result.warnings`，命令处理里的 `ui.warn` 能让用户看到警告。仍不回滚已成功的换根。
