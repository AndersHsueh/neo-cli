# v0.4.29 —— gitignore 字符类与转义对齐 git

## 为什么

非 git fallback 的 `.gitignore` 解析三处与 `git check-ignore` 不符：

1. `[]abc].txt`：`]` 作字符类首字符被截成空类
2. `[!]`：空否定类被编成 JS 的 `[^]`（任意字符），语义相反
3. `foo\ bar.txt`：转义空格变成字面反斜杠

## 改了什么

`charClassEnd`、空类 → `(?!)`、首字符 `]` → `\]`、反斜杠产出字面字符。

## 测试

全量 1118 pass / 0 fail；`tsc --noEmit` 干净。期望值以 `git check-ignore` 为准。
