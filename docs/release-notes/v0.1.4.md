> 2026-10-18 · 次要版本：task 子代理 + wiki 技能代码化

## 新增

### task 工具 —— 派生子代理，隔离上下文

主代理可通过 `task` 工具派生一个子代理，在独立上下文中完成自包含任务，只把最终报告返回给主代理。子代理烧掉的上下文不占用主窗口——大范围代码探索、批量机械读写、跑测试并汇总结果不再撑爆主上下文。

- **复用 Agent 主循环**：预算提示、自动 compact、abort 链路全部继承；工具集裁掉 `task` 自身，结构性禁止递归派生（深度 ≤ 1）。
- **三层档位决策**：主代理在参数里声明（首选）→ 规则信号词兜底（深度信号优先于机械信号）→ 沿用主代理当前档位。机械读写任务派 fast 档省钱，深度推理派 deep_reasoning。
- **cfg 浅拷贝隔离**：子代理切档不污染主代理配置（`applyTier` 是原地改写）。
- **审批可达**：子代理输出静音，但 `confirm`/`warn` 委托主 console——ask 模式下子代理的写操作正常弹审批框，不会被静默拒绝。
- `registerTool()` 运行时注册（返回注销函数），工具层类型下沉 `tools/types.ts` 叶子模块，解开 task → agent → tools 循环依赖。

### wiki 技能代码化 —— 四个 karpathy-wiki-* 技能退役

原四个「写给模型看的纪律手册」技能（new / ingest / query / lint，合计约 105KB）全部退役，能力内化为代码。护栏从「模型读说明书自律」改为「代码 throw 保证」：

| 原来在技能里 | 现在 |
|---|---|
| 断链/orphan/摘要/日期戳/链接密度检查 | `src/wiki/lint.ts`（sh 脚本 TS 重写），`/wiki-lint` 命令 |
| 回填决策、命名约束、INDEX/log 同步 | `wiki_write` 工具内部强制校验——写回的唯一合法路径 |
| 「何时查 wiki」 | INDEX 主题清单注入 system prompt + `wiki_search` 工具 |
| 脚手架 6 模板 + ingest 流程说明 | `src/wiki/templates/`，`/init` 直接读，不碰技能目录 |
| ingest 触发 | 用户手动 `/ingest [full\|incremental]` |

- **`/ingest`**：无参按 `wiki/log.md` 最近一次 ingest 时间判定——超 1 周自动全量（执行前告知），1 周内增量；显式 `full` / `incremental` 可指定。编译交给 fast 档子代理执行，显示计划后直接开始（无确认步骤）。`ingest(snapshot) → 变更集` 纯函数接口，为将来自动化留路。
- **raw 语义**：可创建、可删除、删除后可重建同名；唯独不可修改已存在文件的内容（`write_file`/`edit_file` 在审批前拦截）。不做校验和、不防 shell 绕过——护栏只防 agent 手滑，不防人有意为之。
- **AGENTS.md 区块所有权**：`/init` 只重写 `neo:wiki-workflow` 标记之间的区块，用户手写的「约定/踩坑」不再有被覆盖的风险。
- **新建项目形态**：`/init` 创建 `.neo/wiki/{raw,wiki,outputs}` + `skills/`（空目录，用户自建技能入口），不再从 `~/.neo/skills` 软链任何技能。
