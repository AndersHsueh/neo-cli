# v0.4.49 — `@path` 引用漏剥弯引号右半边

## 问题

v0.4.48 补了中文右括号 / 书名号，但仍漏了弯引号右半边 `” ’ 〞 〟`。用户写「见 @a.ts”」时 path 变成 `a.ts”`，`exists()` 失败，引用**静默不展开**。

| 输入 | 旧 path | 应得 |
| --- | --- | --- |
| `见 @a.ts”` | `a.ts”` | `a.ts` |
| `见 @a.ts’` | `a.ts’` | `a.ts` |
| `见 @a.ts”’）` | `a.ts”’）` | `a.ts` |
| `见 @“a.ts”` | `“a.ts”` | `“a.ts`（只剥尾部右引号；左引号保留） |

## 根因

`TRAILING_PUNCT` 仍是手工枚举。v0.4.48 补齐了括号/书名号，弯引号右半边是同一枚举的下一处遗漏。左引号 `“ ‘` **故意不进集合**：只剥尾部，避免把 `@“a.ts”` 的左引号当尾随标点误剥。

## 改动

- `src/input/completion.ts`：`TRAILING_PUNCT` 补 `”’〞〟`
- `tests/references.test.ts`：新增「剥掉中文引号（含左引号被误剥的一半）」
