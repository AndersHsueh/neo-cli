## C. 对比要点

| 维度 | macOS（旧实现已可用） | sp7 Ubuntu（旧实现全灭） | 新实现 |
| --- | --- | --- | --- |
| shell 路径 | `/bin/zsh` 存在 | `/bin/zsh` 不存在 | 自动探测 → `/bin/bash` |
| 登录 shell 的 PATH | path_helper 重排，bun 仍可见 | `~/.profile` 追加 `~/.local/bin`，bun 可见 | 父进程 PATH 前置，双保险 |
| prompt 环境块 | 无 | 无 | 平台/shell/资源/工具/约束 5 行 |
| 子代理提示词 | 4 行通用说明 | 同 | 增加紧凑环境块 |
| 模型侧效果 | 可能写出 macOS 专有命令 | 完全无法执行命令 | 命令可执行；知道「无 GUI / 非 root / bash」 |
