## 3. 登录 shell vs 非登录 shell 的 PATH（修 PATH 保真的依据）

非登录（sshd `bash -c` 默认）：

```
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/games:/usr/local/games:/snap/bin
bun: 未找到（command -v bun 为空）
node=/usr/bin/node (v24.15.0)
git=/usr/bin/git (2.43.0)
python3=/usr/bin/python3
```

登录（`bash -lc`，耗时 32ms，正常）：

```
LOGIN_PATH=/home/anders/.local/bin:/home/anders/local/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/usr/games:/usr/local/games:/snap/bin
bun=/home/anders/.local/bin/bun (1.4.4)
node=/home/anders/.local/bin/node（nvm 提供，v26.9.0；系统 /usr/bin/node 是 v24.15.0）
git=/usr/bin/git
python3=/usr/bin/python3
```

结论：
- 登录 shell 能拿到 `~/.local/bin/bun`（`.profile` + `.bash_profile` 追加），非登录不能；
- 旧实现虽然传了 `env: {...process.env}`，但 `-l` 会重置 PATH —— 必须做「父进程 PATH 前置」，
  否则在服务器上 `shell` 工具里 `bun` 不可见（即使 shell 路径修对了）；
- login 模式实测 32ms，可接受，默认 `login:true`。
