# 目标驱动自动续跑 `/drive` PRD（issue #24）

> 状态：实现中（待审查）
> 关联：GitHub #24。**与既有 `/goal` 是两件事**，文档写死：
>
> | 命令 | 语义 | 依赖 |
> |---|---|---|
> | `/goal <文本>` | **目标锚**（防跑偏；每轮注入给模型，模型不能改写） | 跨会话信箱 |
> | `/drive <检查命令> -- <提示>` | **可验证完成条件 + 自动续跑**（本单新增） | 仅交互会话 |

## 1 背景

现有 `/goal` 只是静态锚点：不会在回合结束后评估、也不会自动开下一轮，长任务仍是「盯梢式」。

## 2 需求

1. **验证优先；无法验证时接受模型判断，并单独标注来源**（issue #50 修正，见
   `docs/goal-drive-judge-prd.md`）：
   - 检查命令 exit 0 = **已验证**（verified），这是硬条件，优先于一切；
   - 用户显式 `--judge "<完成标准>"` 时，检查命令未过（或没有检查命令）再问模型判断，
     达成则停止推进，但来源标注为**模型判断**（model），**绝不冒充「已验证」**；
   - 没有 `--judge` 时行为与旧口径完全一致：只有 exit 0 才算完成。
2. **语法**：
   - `/drive <检查命令> -- <提示>`：设定条件 + 未达成时自动发送的提示（最多 5 轮）；
   - `/drive --max N <检查命令> -- <提示>`：自定义自动推进上限（1–20）；
   - `/drive`：状态（状态 / 已推进轮数 / 检查命令 / 最近一次检查输出尾部）；
   - `/drive stop`：随时停止。
3. **每轮结束评估**：跑检查命令（60s 超时）——
   - exit 0 → 停止并告知「目标达成」；
   - 未通过 → 自动把提示排进下一轮（注入的拍在 scrollback 回显一行 `❯ <提示>`）；
   - 已到上限 → 停止并告知；
   - 连续 2 轮「模型没有调用任何工具」→ 暂停，把控制权交回用户（防空转烧钱）。
4. **忙时不叠加**：轮末若有 turn 在跑或队列非空，这一拍**跳过**且不计数（下一轮再试）。
5. **安全与权限**：检查命令是用户显式配置的（与 hooks 同口径：**不经审批、按配置自动跑**，PRD 与 README 明写）；
   自动续跑的轮次本身仍走既有权限模式（ask 下照样弹审批）。
6. **非交互**：`-p` 不提供 `/drive`（命令会明确提示不可用）。
7. 会话退出 `stop()`，不再往已退出会话里排轮。

## 3 验收

1. 用户可设定一条可验证完成条件；设定后至少自动推进一轮；
2. 每轮结束有评估：未满足 → 自动续跑；满足 / 不可恢复（到上限 / 连续空转）→ 清除并告知；
3. `/drive stop` 可随时停；连续无工具调用 N 轮自动暂停（默认 2）；
4. 权限模式不变（非 `-y` 时子轮里的写操作仍要审批）；
5. 与 `/goal` 并存的语义在 PRD / README / help 里写清；
6. `bun x tsc --noEmit` 零错误、`bun test` 全绿（含 PTY）、`bash scripts/verify.sh` 为 `ALL GREEN`。

## 4 非目标

- ~~不用小模型「评估条件是否达成」~~ —— **已由 issue #50 修正**：用户显式 `--judge` 时接受模型判断，
  但来源必须标注为「模型判断」而非「已验证」，口径见 `docs/goal-drive-judge-prd.md`；
- 不做「模型判断代替检查命令」的默认行为（只有显式 `--judge` 才启用）；
- 不做 `/goal pause|resume` 状态机（`/drive stop` + 重新 start 即可）；
- 不持久化到 session（进程退出即结束）；
- 不做无人值守的 `-p` 长跑（非交互模式不提供）。
