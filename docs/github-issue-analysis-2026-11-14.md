## 5. 依赖、边界与需要协调的关系

1. **#64 与 #56 共用 hooks 基础，但正文明确要求保持边界。** 两者都复用 #3 已有的配置、matcher、退出码和 `/hooks` 展示；#64 只补 `SessionStart`、`UserPromptSubmit`、`Stop`、`PreCompact`，`Notification` 仍由 #56 跟踪。适合统一事件 JSON、错误处理和展示约定，不宜因共用基础设施就合并范围。#57 也可复用 hooks 的命令执行与超时机制，但它是状态栏渲染，不是新生命周期事件。
2. **#65 明确不依赖 #55，也不同于 #61。** #65 可在现有会话落盘与 `--resume` 上实现复制分叉，不需要先完成 supervisor/attach；#61 是不落历史、无工具的旁支提问，#55 是断线后继续运行。三者应保持语义和文档边界。#61 的“转为带工具后台子代理”只是可选扩展，不是其基础版前置条件。
3. **#53 明确不依赖 #36 或 #52。** 它要求使用现有后台子代理和固定提示/工具白名单，不必等待命名子代理；同时必须处理 CaptureEngine 队列、wiki 锁与重复写入风险。#53 的内部阶段触发也不能简单替换成 #64 的用户 `Stop` hook 或现有 `TurnEnd` 用户脚本。
4. **#63 与 #54 可在路径作用域上协调，但正文将二者视为不同功能。** 多根目录落地后，需要明确各根下嵌套 `AGENTS.md`/`CLAUDE.md`、补全、搜索和仓库地图的行为；这不是要求先做 #54。#63 还明确与 #9 worktree、#36 命名子代理正交。#52 若先关闭仓库地图默认值，#63 的仓库地图验收应在显式启用该能力的配置下验证。
5. **#55 不应与 #35 的后台 shell PTY/attach 混为一项。** #55 正文已明确：#35 的 attach 指后台 shell，不是会话级 supervisor。二者可借鉴进程托管经验，但验收对象不同。
6. **#35 是索引且存在需要复核的状态漂移。** #35 仍将“LLM 评估完成条件”和“`-p` 无人值守长跑”列为未做；但 #59 称 `-p --drive / --max-minutes` 已上线，#52 也描述了模型判断与 `-p --drive` 的现有行为。因此至少这两项目前需要核实和更新，不能直接把 #35 的勾选状态当作最新事实。#35 自身要求开工时拆独立 Issue，不宜作为一个大实现单直接开发。
7. **#38、#36、#60、#37 有复用机会，但正文没有声明硬性前后置。** #38 可在后续把 #36 的命名子代理纳入插件包；#60 与 #37 都涉及对外事件表达，可探索共享事件模型，但 ACP 是编辑器协议、stream-json 是 `-p` 输出格式，不能视为同一个交付。

## 6. 建议的处理顺序（非仓库官方优先级）

以下只是依据正文所述影响、范围与依赖给出的工程建议，**不代表仓库官方优先级，也不改变任何 Issue 状态**。

1. **建议先处理 #52。** 正文给出了可复现的 CI 假阳性风险：检查命令失败时，模型仍可能使 `-p --drive` 以 0 退出。该单同时明确了退出码、默认配置、文档和验收边界，适合作为正确性收口优先项。
2. **建议随后处理 #59，并搭配 #37 提升无人值守可恢复性与可观测性。** #59 面向网关/模型波动导致的长任务中断；#37 让 CI 与上层编排实时看到工具、文件和轮次进展。两者可以独立推进，但共同服务无人值守场景。
3. **建议将 #64 与 #56 作为相邻批次协调实施。** 先统一 hooks 事件约定，再分别交付生命周期控制和通知，能复用基础而不混淆范围。#57 可作为同基础设施上的独立小项；其正文将自身描述为“低成本、高感知”，但这不等于已经完成工作量评估。
4. **建议用边界较清楚的交互项分散大功能风险。** #62、#61、#65 都有明确用户场景；其中 #62 与 #61 正文分别称功能/实现面较小，#65 明确无需等待 #55。实际排期仍应先确认主轮次并发、TUI 状态和会话隔离等细节。
5. **建议对 #55、#60、#38 先控制首版范围。** #55 可先限本机 supervisor、attach/list/stop；#60 涉及协议、权限与 diff 等较大集成面；#38 涉及包清单、来源和安装生命周期。它们不适合作为未拆分的“小修补”。#53 虽已有详细设计，实施时仍应把捕获队列、并发锁和失败降级作为验收重点。
6. **建议尽快整理 #35。** 先核对已经变化的事项、更新索引，再把仍需实施的项目拆成独立 Issue；同时保留#55 与后台 shell attach 的区分，避免重复排期或误关。
