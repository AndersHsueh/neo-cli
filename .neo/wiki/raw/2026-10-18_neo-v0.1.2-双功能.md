## 功能一:工具调用预算(commit 1edc374)

### 用户原话(需求)

- 工具调用每次从 40 轮最多改到 80 轮
- 每一轮对话应答开始(主循环开始),除了可用工具,也要传一个本轮工具调用次数(1/80);第 2 次调用则告诉模型(2/80),以此类推
- 目的:防止模型调用次数超过限制导致最终答案失败
- 模型吐出最终答案结果时,这个值归 0,准备下一轮调用

### 方案审阅中的拍板

- 注入位置:临时 system 消息(用户接受我的推荐,否了 tools 数组与 tool 消息尾部)
- 计数语义:iter+1(第几次 LLM 请求),与硬上限严格对齐
- 用户补充要求:剩余 ≤5 的提示里必须带具体剩余次数,不能只写「即将耗尽」——「防止在 <= 5」(原话,语义为防止模型在剩余不足时仍不收敛)

### 实现要点

- budgetMessage()/dropBudgetMessage() 在 src/agent.ts;push → chatStream → pop,catch 路径也摘
- dropBudgetMessage 用 lastIndexOf 按引用比对,防误删内容相同的消息
- max_tool_iterations 默认 40→80:config.ts + settings.example.json;settings.json 被 gitignore,本地另改(踩坑五的同步义务)
- 截断警告文案改为「本轮被截断——上面的回答可能不完整」

### 验证

- tsc 干净;264 pass / 1 skip / 0 fail
- mock chatStream 探针跑满 79 次请求:计数 1→80 递增、第 75 次起出现收敛提示、历史零残留

### 实战实证

- 2026-10-18 会话中真实生效:用户看到「本轮工具调用:第 2 次 / 上限 80」注入;用户报告此前会话撞过 40 上限(旧配置运行中实例)

## 功能二:热键系统(commit 8c08cdc)

### 用户原话(需求)

- 热键监视:主循环开始了,但用户发现输入是错的或不完整的,允许按 ESC 取消当前操作,回归等待输入界面
- 澄清 1:以后可能有按上/左方向键各有不同功能,要有一个专用的监控用户输入的模块
- 澄清 2:Ctrl+C 现在功能没问题但太突兀,着急会按错;模仿 Claude Code,按下后屏幕下方显示 2 秒橙色字(用户给的英文不合语法,由我改为 "Press Ctrl+C again to exit")

### 方案阶段的关键认知修正

- 我最初判断「raw mode 会破坏 readline 行编辑,要谨慎」——错误。readline 在 TTY 上默认就是 terminal 模式,stdin 本就全程 raw mode,行编辑是 readline 自己解析按键实现的
- 因此 keypress 监听是正解,不存在抢字节流;「另开 raw-mode stdin 监听会重复回显」警告的是 stdin.on("data"),不适用 keypress
- Ctrl+C 归 SIGINT 信号语义不经 keypress,否则运行中一次 Ctrl+C 触发两路

### 最终语义(用户确认)

- ESC:空闲无操作 / 运行中取消本轮+历史回滚到本轮开始(含 user 消息)
- Ctrl+C ×1:橙色提示 2s / 中断请求(半截历史保留)+提示
- Ctrl+C ×2(2s 内):退出
- 两种中断不同语义是刻意的:ESC 面向「输错了重来」,Ctrl+C 面向「停下但保留进展」

### 实现要点

- 新增 src/hotkeys.ts:HotkeyRouter(attach/detach/on,mapKey 只认无修饰键)+ doubleStrike(双击状态机,超时解除武装)
- Agent.send 增 opts.rollbackOnAbort;Console.flashNotice
- index.ts:exitStrike 挂 SIGINT;hotkeys.on("escape") 仅 draining 时 cancel;drain 传 rollbackOnAbort: true

### 测试基建教训(重要)

- 第一版用 mock.module("../src/llm.ts") 注入假 chatStream,单文件全绿,全量跑 skill-budget.test.ts M4 假失败——bun test 单进程共享模块表,mock 泄漏
- 正解:AgentOptions.chatStream 构造注入点,缺省回落真实实现
- 另一坑:AbortSignal 上没有 abort()(在 controller 上),mock 里走 agent.cancel()

### 验证

- tests/hotkeys.test.ts 13 用例;全量 277 pass / 1 skip / 0 fail;tsc 干净
