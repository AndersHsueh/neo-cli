## 二、v0.1.0-rc 期间的配置坑(fast 路由模型判死)

- 现象:`settings.json` L44 `model_routes.fast.model = "l-deepseek-v4-flash"` 时,3 个 backend 池乱跳,最短 0.52s / 最长 **180.51s**,std ≈ 87s,差 350×,判死
- 处置:删除该字段,回落 provider 端 `ipsa.fast_model_name = "deepseek-flash"`;改后最短 0.98s / 最长 1.40s,std ≈ 0.2s,稳
- 依据:`routeModel()`(`src/config.ts:421`)的回落逻辑;Huang 2026-10-16 n=3 实测
- 关键约束:`settings.json` 在 gitignore 中(本地配置不进版本控制),此类修复必须用户手动同步,release note 单列「不进 git 的配置变更」一节
