# 记忆激活 v0.1.11

## 摘要

v0.1.11 把记忆系统从「只写不读」接通为双作用域闭环：项目级 `.neo/wiki` 沉淀决策/踩坑/进度，用户级 `~/.neo/wiki` 沉淀画像/偏好；轮末 fast 档自动归纳，下轮先项目级后用户级召回注入。`-p` 单次模式只用项目级。

> 最后更新:2026-10-20
> 来源:docs/001-memory-system-design[done].md §7 · release-notes/v0.1.11.md

## 交付清单

- **存储**：双作用域布局（项目级/用户级同构）、用户库懒创建、原子写、跨进程写锁 + 残留锁自愈（修复 `mkdirSync(recursive:true)` 吞 EEXIST 的存量 bug）。
- **读链路**：R0 双库 INDEX + 用户画像摘要注入；R1 每轮自动召回（严格两桶：项目先、用户后，≤900 token，无命中零注入，临时消息轮末摘除/abort 回滚/压缩过滤）；R2 `wiki_search` scope、`remember` 工具。
- **写链路**：T1 轮末 boundary 价值判定、T2 压缩前、T3 显式、T4 退出 flush；journal 先落盘再提炼，失败可恢复；提炼 JSON 硬校验（置信门槛/evidence 必须可回溯/密钥丢弃/页名与摘要强制）；合并去重、supersedes 更正、单页 16KB 转续页。
- **推断标记**：用户级事实/推断分区，推断条目带日期/置信/session，召回加 `[推断]` 提示，敏感类别禁止推断。
- **命令面**：`/memory status|list|recall|why|flush|forget|migrate|lint|on|off`、`/remember`。
- **迁移**：`/memory migrate` 归档旧 `~/.neo/memorys`（非破坏、幂等），旧首条输入索引停写。

## 验证

- 单测：496 pass / 1 skip / 0 fail（22 文件），tsc 零错误；新增 4 个记忆测试文件，含真实子进程锁测试与 Agent 注入生命周期。
- 真实链路 E2E：`-p` 写入 → 下次启动 journal 恢复 → 落页 `约定-提交信息规范.md`（来源行/INDEX/log 同步）。
- 设计取舍与回滚方案：见规格 §7.18（配置开关可一键停用，迁移不删旧数据）。
