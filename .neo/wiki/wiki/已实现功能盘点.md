## 2026-10-19 粘贴增强 M2 完成：macOS 贴图全链路

- **交付**：`src/clipboard.ts`（JXA 临时文件协议——P2 定案：stdout 污染/退出码失效，以文件存在性为判据、stderr 做诊断）；hotkeys `paste-image`（Ctrl+V/Alt+V）；`Message.content` 扩为 `string | ContentPart[] | null`，新增 `contentText()` 收口辅助（compact/预览/子代理/测试全部走它，禁止散落 instanceof）；estimateTokens 图片固定 800 tok/张；附件落盘 `attachments/<sessionId>/img-N.png` + JSON `$ref` 指针（C10 NEO_SESSIONS_DIR 注入），loadSession 出口统一 hydrate，缺失降级 `[Image #N 已丢失]`；C1 空闲判定（draining/queue/selectActive/questionPending 四态）；C6 上限可配置。
- **E2E 抓出的真 bug**：mapKey 的 `case "v"` 写在 `if (k.ctrl || k.meta) return null` 守卫**之后**，Ctrl+V 永远不可达——第一轮 E2E 全挂才暴露。教训：单测 fake 全绿不代表接线正确，守卫顺序类 bug 只有真实按键路径能暴露。已修 + hotkeys 单测钉死（裸 v 不触发）。
- **验证**：真实剪贴板 pty E2E 六判定全过——chip `[Image #1]` 显示、「已附加 (0KB)」提示、会话 JSON 用 image_ref 且零 base64、附件 PNG 落盘、模型回复「收到了——是一张深红色的小图」（1×1 红 PNG，多模态真实生效）、resume hydrate 重组回 data URL。全量 400 pass / 0 fail / 1 skip，tsc clean。
- **M3 待办**：Windows/WSL（PowerShell 单次 spawn）+ Linux（wl-paste/xclip）分支；PRD 文件名待 M3 收尾后加 `[done]`。

## 2026-10-19 粘贴增强 M1 完成：多行粘贴不再拆成多条消息

- **修掉的 bug**：多行粘贴此前被 readline 逐行提交（3 行 = 3 次独立 LLM 调用），粘贴内容含回车即误提交——这是 v0.1.8 时代的存量正确性问题，不是体验优化。
- **路线**（探针定案，PRD §7 已更新）：PRD 原设路线 A/B 全部失效——粘贴内 line 在粘贴过程中逐条提交，paste-end 时刻清缓冲无法追回。实际路线「粘贴期间丢弃 + paste-end 重组」：启用 `\x1b[?2004h` → paste-start 收集 → 期间 line 入栈（C11 同款）→ paste-end 取 `rl.line` 缓冲组装全文 → 含 `\n` 必折叠为 chip（readline 行缓冲装不下换行，写回会再次逐行提交，结构性约束）→ 发送时 resolveLine 还原原文。
- **交付**：`src/paste.ts`（PasteCollector 状态机 + shouldFold + assemblePaste）、`src/attachments.ts`（chip 生成/绑定/还原，编号会话内递增）、hotkeys 加 paste-start/paste-end 键名、index.ts queue 升级 QueuedLine、config 加 paste.* 块（fold_lines/fold_chars，默认 3/300）、退出时写 `2004l` 还原终端。
- **验证**：17 条单测（折叠边界/生命周期/组装/还原含「手打 chip 不误还原」）；真实 pty E2E 四判定全过——chip 显示 `[Pasted text #1 +3 lines]`、模型回复含全部三个标记（全文送达）、ALPHA/BETA/GAMMA 各只出现 1 次（无逐行提交）、退出输出含 `2004l`（终端还原）。全量 383 pass / 0 fail / 1 skip，tsc clean。
- **已知限制**（M1 明示）：终端不支持 bracketed paste 时无标记，行为退化为现状（非回归）；粘贴发生在光标处，光标在已打文字中间时 chip 替换整行，原文在附件 content 里不丢；`paste.fold_lines` M1 不生效（结构性预留 M2+）。
- **待办**：M2 剪贴板贴图（P2 探针未跑）；PRD 文件名尚未加 `[done]`（M1 只是分期之一，等 M2/M3 收尾再改）。
