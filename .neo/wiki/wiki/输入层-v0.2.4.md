# 输入层-v0.2.4

> 最后更新:2026-10-25

## 摘要

v0.2.4 补齐 neo 的输入层：`@` 文件补全（Tab）、`@path` 引用展开（内容随消息送达）、`/` 命令补全、`Ctrl+J` 多行输入。
仍然不换渲染模型 —— Tab 由 `HotkeyRouter` 接管并改写 `rl.line`，多行用 continuation 状态机。
开工前做了 bun readline 的 M0 探针（P1~P7），**推翻了自己最初「bun 不支持 completer」的误判**：真 PTY 下原生 completer 可用，缺的是 cursor 入参与排序/样式可控性。用例 569→660（37 文件），PTY 10/10，`scripts/verify.sh` ALL GREEN。

## 关键决策

| 决策 | 理由 |
|---|---|
| Tab 自接管 + 注册 **no-op completer** | 原生 completer 不给 cursor（`@` 需要「光标前 token 精确替换」）、排序与候选列表不可控；不传 completer 时裸 Tab 会被当字面 `\t` 插进缓冲 |
| 文件索引 `git ls-files` 优先、**异步后台刷新** | 2 万文件同步 `Bun.spawnSync` 实测 75ms 会卡按键；启动 await 预热一次，之后按键只读缓存 |
| `@path` 引用**附在原文末尾**而不是替换 token | 保留用户原话（模型据此理解意图），引用块带 `——— path（N 行）———` 起止标记 |
| 预算「超限**截断**」而非「整份跳过」 | 最常见的是 70KB 的中等模块，整份跳过等于引用功能失效；先 `stat` 再 `readSlice`，不为 50MB 文件整读 |
| `Ctrl+J` 只在**真 TTY** 下等于续行 | 管道/脚本里 `\n` 是行终止符；否则 `printf '/help\n' \| neo` 会退化成续行（回归实测踩到） |
| 换行判定走 stdin `data` **队列** | keypress 与 line 的先后由监听器注册时机决定、不可靠；一个数据块可能产生多个 line 事件；CRLF 只算一个 Enter |

## 实现落点

| 文件 | 内容 |
|---|---|
| `src/input/completion.ts` | 触发识别（`@` 边界 / `/` 命令）、模糊打分、有界 top-k、`applyMatch`、候选提示 |
| `src/input/commands.ts` | 33 条命令声明表；与 `handleCommand` switch 的双向漂移守卫在 `tests/commands.test.ts` |
| `src/input/fileIndex.ts` | git 清单 + FS 回退 + 异步 TTL 刷新 + 软链目录判定（内联，不依赖 skills） |
| `src/input/references.ts` | `@path` 解析 / 展开 / 预算截断 / 绝对路径去重 |
| `src/input/multiline.ts` | continuation 状态机 + `newlineKindsFromBytes` 队列 |
| `src/index.ts` | no-op completer、Tab 接管（循环/光标）、Ctrl+J 续行、引用展开 |

## 三个真 PTY 才能发现的 bug（simplify 阶段）

1. **`rl.prompt()` 把 cursor 归零**：Tab 补全后继续输入会变成 `X@a.txt`。改用 `_refreshLine()`，并加 S9 断言光标位置。
2. **Tab 连按循环不成立**：第二按时 token 已变成候选本身 → 重新搜索、候选集缩小，首轮候选永远轮不到。改为记住「上次应用后的整行 + 插入区间」。
3. **候选提示行被自己擦掉**：提示写完光标停在行尾，`applyLine` 的 `\r\x1b[2K` 把提示清了。提示改为自带结尾换行。

## 验证

- `bun test` **660 pass / 0 fail（37 文件）**；`tsc --noEmit` 零错误。
- `bash scripts/verify.sh` **ALL GREEN**，PTY 10/10（S5~S10 为新场景；S9 光标、S10 连按 Tab）。
- 红态：`git archive HEAD`(v0.2.3) + `NEO_ENTRY` 跑同一套，S5~S10 全红、S1~S4 绿。
- 探针：`scripts/readline-probe.ts` + `docs/v0.2.4-m0-probes[done].md`（P1~P7）。

## 已知边界

- 带空格的 `@` 路径、`@` 目录展开不支持（需要引号语法）。
- Tab 只在空闲时接管（agent 运行中 / 审批问句 / select 期间不补全）。
- 命令行内不提供 `@` 补全（避免补出来的 `@x` 提交时被静默忽略）。
- 索引上限 20000 条；超大 monorepo 可能只覆盖前 2 万。
