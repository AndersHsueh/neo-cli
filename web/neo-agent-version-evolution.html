05 / KNOWN BOUNDARIES

已知边界

限制与能力同属发布事实。以下条件不应被「终端自动化」或「长任务」的表述掩盖。

  • 运行前提与分发

    需要自备 Bun >=1.1、兼容的 LLM 网关与 API key。package 当前为 private: true，没有公开 npm 包事实；使用入口是仓库源码与 neo 命令。

  • 平台验证不对等

    README 记录 macOS、Ubuntu / Debian 有实测；Windows 11 为实验性，未实机验证，不能据此宣称正式支持或全平台一致。

  • worktree 只隔离文件

    托管 worktree 提供独立 git 检出，减少并行会话互相覆盖文件的机会；它不是安全沙箱，也不是权限边界。

  • hooks 不是权限系统

    hooks 只能在既定时机阻断调用或回到既有审批，不能把调用升级为免审批；它不提供沙箱，权限仍由模式与审批闸门负责。

  • 模型判断不等于验证

    v0.4.84 会区分 source=verified|model，但该版本 -p --drive 对两种 done 均记录退出码 0。#52 已实现该退出码修正并推送至 main（检查验证 0 / 仅模型判断 3），但尚未发版；不能把它当作已发布 v0.4.84 的能力。

  • 暂停项没有随新版解锁

    v0.4.84 明确记录 #28 的交互式 PTY / attach、Ctrl+B 与跨会话后台进程暂停，#29 OAuth 浏览器登录同样暂停；已有 MCP HTTP / SSE 不等于已有 OAuth。
