neo-agent 是 neo-cli 仓库中的 Matrix 风格终端编程助手，命令行入口为 neo。它通过 Bun 运行，可连接 OpenAI 兼容或 Anthropic Messages 协议的 LLM 网关。

把终端编程、长任务验证与多会话协作放进同一个 CLI。

CAPABILITIES / 事实分层

为真实终端工作流而生

从模型路由到文件工具，再到无人值守长跑：已发布能力与本轮实现分别标注，不把未发布能力写成已发布功能。

01 / ROUTING 已发布

多协议与可控模型路由

连接你已有的 OpenAI 兼容或 Anthropic Messages 网关，用 provider / tier / model 路由明确每一次请求的去向。

  • 规则或 LLM 分类器，支持显式切档
  • 上下文探测、压缩与输出预算防护
  • 跨协议保留会话、工具与用量语义

现有 fallback_allowed 是档位目标不可用时向 default 档降级，不是 #59 的有序模型备用链。

02 / WORKSPACE 已发布

终端内编程、协作与记忆

把读改文件、搜索、shell、审批与会话恢复留在同一个 CLI，并按需接入 MCP、LSP 和仓库地图。

  • 前台跨会话消息与后台子代理
  • 托管 worktree、后台 shell 与任务续聊
  • 双作用域记忆 wiki、按轮回滚与定点压缩

权限模式与审批仍然生效；worktree 和 hooks 都不是安全沙箱。

03 / UNATTENDED

面向无人值守的可信执行

现有长跑提供检查与来源标记；恢复、结构化事件和退出码修正逐项列出真实状态。

已发布

-p --drive 目标驱动长跑

每轮结束执行检查命令，提供轮次、工具迭代和墙钟上限，并区分 verified / model 来源。模型判断不等于验证。

已实现，未发布

#52 · 退出码正确性修正

已实现把 verified / model 来源落实到进程退出码：检查验证 0、仅模型判断 3，避免 CI 把模型自判当作检查通过。尚未发版。

已实现，未发布

#59 · 有序模型备用链

已实现主 Agent 按用户配置的 provider + model 顺序有界切换；成功才提交目标、会话内保持，用量按实际模型分桶。提高恢复机会，不保证任务成功。

已实现，未发布

#37 · stream-json 事件流

已实现以 JSONL 逐行输出九类事件与恰好一个最终结果，stdout 纯 JSONL、诊断走 stderr；提高可观测性，不替代测试。

WORKFLOWS / 可复制命令

四种进入仓库的方式

命令直接来自 README。交互模式保留人工审批，非交互与无人值守场景则明确使用 -y。

01

交互开发

在仓库中读文件、编辑、跑命令，通过 ask、auto-edit、auto-all 或 plan 控制权限。

02

-p 单次执行

给脚本或自动化一个明确任务，一轮结束后退出；已有 text 与结束时单行 json 输出，尚无 stream-json。

03

--drive 无人值守长跑

以真实检查命令作为验证信号，并限制轮次与墙钟时间。无人值守必须显式 -y。

04

worktree + 跨会话协作

在三个前台终端分别启动编排者与两个 worker；文件隔离由 worktree 负责，会话寻址由名称负责。

跨会话消息只覆盖存活的前台交互会话，不是持久 supervisor；worktree 只隔离文件。

BOUNDARIES / 先说明限制

平台、权限与验证边界

终端工具可以执行真实操作。了解前提与限制，再决定哪些任务适合交给它。

  • 平台支持并不等同

    macOS、Ubuntu / Debian 有实测；其它 POSIX shell 有解析器支持。Windows 11 为实验性，尚未实机验证，不宣称正式支持。

  • 文件隔离不是安全沙箱

    worktree 只隔离文件，hooks 不是权限系统，两者都不是安全沙箱。shell、MCP 与用户脚本仍可能产生真实副作用。

  • 模型判断不等于验证

    v0.4.84 已标注 verified / model 来源，但进程退出码尚未按该来源拆分。#52 已实现该修正并推送至 main（验证 0 / 模型判断 3），但尚未发版，不能当作已发布版本已具备的能力。

  • 无人值守仍有明确前提

    需要自备 Bun、兼容网关与 API key；-p --drive 必须显式 -y。轮次、工具迭代和墙钟上限用于约束任务，不保证检查最终通过。

  • 本轮实现尚未发版

    #52 默认能力收口与退出码、#59 有序备用链、#37 stream-json 已实现、验证并推送至 GitHub main，但没有新 tag、release note 或发布日期，不属于当前已发布能力。持久 supervisor / attach、OAuth 与 ACP 仍不在范围内。
