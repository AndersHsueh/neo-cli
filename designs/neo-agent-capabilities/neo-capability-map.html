neo 能力概要图

Matrix 风格的终端编程助手。一个用 Bun 写的 CLI harness，把模型、工具、记忆、多会话协作收进同一个可自托管的循环里： 双协议接入、四档模型路由、双作用域记忆，以及一条从输入框通到写盘审批的完整链路。

01

能力栈

stack

一次请求自上而下穿过六层；宿主能力经回调注入，模块边界以文件为单位。

  1. L1

    入口与交互

    src/index.ts · src/tui/

    TUI 底部常驻状态条 + 输入框；-p 单次模式、管道/CI 降级 readline；! shell 直通与工具共用审批。

  2. L2

    会话与协作

    src/session.ts · src/mailbox/ · src/worktree.ts

    会话持久化 / 恢复 / 导出；代号寻址与 /rename；跨会话消息；托管 worktree 提供文件级并行隔离。

  3. L3

    Agent 循环

    src/agent/loop.ts · policy.ts · compact.ts

    主循环 user → LLM → tool → 回填；四档权限策略、工具预算与目标锚、上下文压缩切点、计划态。

  4. L4

    工具与扩展

    src/tools/ · skills.ts · mcp/ · lsp/

    23 个内置工具、技能三层渐进披露、MCP 外部工具、LSP 代码智能、生命周期 hooks、路径作用域规则。

  5. L5

    记忆与知识

    src/memory/ · src/wiki/ · repoMap.ts

    项目级 + 用户级双作用域 wiki；一轮结束提炼、下一轮召回；回填校验与 lint；仓库地图与环境快照。

  6. L6

    模型接入

    src/llm.ts · anthropicWire.ts · config.ts

    provider × 档位两条正交的轴；协议选择与回退；分类器换档；上下文窗口探测与 max_tokens 防护。

turn path一次 turn 的路径
  1. 01输入 · @ 引用展开、大段粘贴折叠成 chip
  2. 02选档 · 轮次开始分类（off / rule / llm），/why 可追溯
  3. 03组装 · 系统提示 + 环境快照 + 记忆召回 + 路径规则
  4. 04循环 · 流式 → 工具 → 审批 → 回填，直到收口
  5. 05压缩 · 超阈值摘要替换，从安全切点重来
  6. 06收尾 · 轮次诊断落盘，记忆异步提炼不阻塞
02

能力域

domains

八个能力面：既能在界面上看懂，也能在 src/ 里找到实现与测试。

D1

文件与检索

read_file / write_file / edit_file（要求唯一匹配）、glob、grep、list_dir；读带行号与分页。

D2

命令执行

shell 按平台自动选择；超时与退出码；background 后台跑、前台超时自动转后台，shell_output / /ps 回收。

D3

子代理与任务

task 派隔离子任务，可后台（完成自动回注、并发上限 3）；/tasks 管理；todo_write 结构化待办。

D4

技能与规则

技能三层渐进披露、use_skill 按需加载；.neo/rules 只在本轮触达匹配路径时注入，轮末摘除。

D5

记忆与知识

remember / wiki_search / wiki_write；双作用域 wiki；/ingest 编译 raw、/wiki-lint 体检。

D6

外部接入

MCP（stdio + streamable HTTP），工具名 mcp__server__tool 统一治理；LSP 编辑后诊断回灌与只读导航。

D7

多会话协作

send_message / list_peers；mailbox 状态机 + 心跳看门；--worktree 让并行的文件互不覆盖。

D8

安全与治理

ask / auto-edit / auto-all / plan 四档；hooks 只能阻断、不能抬权；/plan、/review 借只读闸门。

@
文件引用与模糊补全：提交时把内容附在消息末尾（≤5 文件 · 单文件 ≤400 行 · 总 ≤60KB）。
!
空输入框键入 ! 进入 shell 模式；与工具调用走同一套权限判定，plan 下拒绝。
Ctrl+V
贴图与大段粘贴折叠成 chip；↑↓ 历史前缀搜索；多行由输入框原生承载。
04

模型接入

routing
TIERfast · balanced · default · deep_reasoning（四档，分类器自动切）
PROVIDERsettings.providers 里的端点；OpenAI 兼容或 Anthropic Messages 协议
↳model_routes 把「档位」绑到「provider + model」，两条轴正交
  • 双协议共用同一条工具调用与审批路径；思维链 reasoning_content 与正文分双流渲染。
  • 分类器 off / rule / llm 同一接口；规则版可解释（/why），升档失败只向上回落。
  • 上下文窗口自动探测 + 溢出学习；超限自动压缩重试一次（compact_threshold 0.75）。
  • 网关回不透明 400 时，把 max_tokens 夹到安全值重发一次：只降不升、每请求一次、不改配置。

06

边界与不做

scope
  • Windows 11 仍是实验性（PD-1）：shell 探测 pwsh → powershell → cmd，尚未实机验收。
  • 跨会话消息 at-most-once，进程崩溃可能丢一条；v1 不做 supervisor / 后台会话 / attach / 跨机。
  • worktree 是文件隔离，不是安全沙箱 —— 权限仍归 /mode 与审批闸门。
  • -p 单次模式只用项目级记忆，不混入操作员个人记忆。
